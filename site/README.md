# site · kmd 소개 사이트

제품을 **소개만** 하는 정적 사이트다(로그인 · 서버 API 없음). 참고: `C:\project\termflow\site`(termflow-about.vercel.app) · `C:\project\CDP\site`(cdp-about.vercel.app).

**화면은 진짜이고 내용은 가상이다.** 시험 지식 「신규 입사 온보딩(테스트)」(`onboard`) 하나를 임시 팀 서버에 세우고, 줄거리를 채널마다 실제 저장 문(`hub.save` · `hub.edit`)으로 지나게 한 뒤 화면을 찍는다.

```
index.html · site.css · site.js   사이트 본체 · 빌드 없음 · 바닐라 JS · 색은 제품 토큰(app/kmd.css :root · 다크) 값
favicon.svg        제품 것 사본
demo/content.mjs   시험 지식(문서 4 · 항목 12)과 줄거리 6걸음 · 사람 김(지식관리자) · test-lee(인사팀) · test-park(IT 지원)
demo/run.mjs       세우기 → 저장 → 화면 찍기(라이트 · 다크 · 1280×800) → data/story.js(그래프 · 문서 · 기록 자료)
shots/             찍은 화면 <이름>-<light|dark>.png(home · kn · doc · item · rec · recs · search · edit · graph · history · held · import)
data/story.js      run.mjs 가 만든다 · 손으로 고치지 않는다
```

```bash
node site/demo/run.mjs              # 다 하기(Chrome 또는 Edge 필요)
node site/demo/run.mjs --no-shots   # 자료만
```

## 줄거리(한 가닥이 한 주 동안 이어진다)

월요일 결정 「노트북을 입사 전날 집으로」 가 계정 · VPN · 첫날 일정 · 받는 법 · 돌려주는 법으로 번진다. 걸음마다 `why`(앞 걸음과 잇는 말)가 사이트에 보인다.

## 마디

| 마디 | 도식 | 움직임 |
|---|---|---|
| 첫 화면 | 한 줄 · 문서 화면 그림 | 없음 |
| 한눈에 | 네 단계 띠: 들어온다 → 한 문에서 검사 → 기록과 문서가 같이 바뀐다 → 찾는다 · 못 넘으면 넣지 못함 | 없음 |
| 개념 | 세 층 · 지식 지도(문서 넷 · 항목 · 문서 링크 · 이번 주에 바뀔 항목 표시) · 기록 하나 → 항목 둘 | 흐르는 점선 |
| 한 주의 이야기 | 요일 시간 줄 · 채널 → 저장 문 → 기록 · 문서 · 넣지 못함 · 걸음마다 잇는 말 + 작은 지식 지도(지금 바뀐 곳 · 앞서 바뀐 곳 · 넣지 못함) + 옛 값 → 새 값 + 화면 | 점이 길을 따라 흐름 · 요일 저절로 넘김(누르면 멈춤) |
| 찾아가기 | 길 띠(목록 → 찾기 → 항목 → 기록 → 문서) + 걸음 목록 + 화면 | 그림 바꿈 |
| 그래프 | 시험 지식 그래프 · 둘러보기 일곱 걸음(노트북 받기 → 월요일 기록 → 계정 발급 · 화요일 커밋 → VPN · 수요일 파일 → 노트북 반납 · 넣지 못함 → 전체) · 점을 누르면 이웃 한 겹 | 점이 피어나고 선이 그려짐 |
| Claude Code | brief → match → section → 일 → save 띠 + 세션 재생 | 글자 치기 · 띠가 같이 켜짐 |
| 화면 · 시작하기 | 화면 12장(크게 보기) · 두 프로그램과 그 사이 길 · 자리 표 | 없음 |

밝기는 시스템 따라 · 머리 단추로 바꾼다(이 브라우저에 `kmd-site-theme`). 그림도 라이트 · 다크로 바뀐다. 움직임 줄이기 설정이면 애니메이션 없이 끝 상태로.
