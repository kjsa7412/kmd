# site · kmd 소개 사이트

제품을 **소개만** 하는 정적 사이트다(로그인 · 서버 API 없음). 참고: `C:\project\termflow\site`(termflow-about.vercel.app) · `C:\project\CDP\site`(cdp-about.vercel.app).

**화면은 진짜이고 내용은 가상이다.** 시험 지식 「신규 입사 온보딩(테스트)」(`onboard`) 하나를 임시 팀 서버에 세우고, 줄거리를 채널마다 지금 저장 문으로 지나게 한 뒤 화면을 찍는다. 사람 채널(세션 · 공유)은 저장 제안(`hub.propose`) → 승인(`proposal` 을 실은 `hub.save`), 화면 고치기는 저장 확인 창 길(`hub.edit` dry → `proposal`), 무인 채널(자동수집 · 수기수집)은 들이기 문(규칙 길까지 늘 들어감)이다. 입력 오류면 아무것도 쓰지 않으므로 스크립트가 거기서 멈춘다.

```
index.html · site.css · site.js   사이트 본체 · 빌드 없음 · 바닐라 JS
site.css           색 · 글 크기 · 간격 · 모서리 · 그림자는 제품 토큰(app/kmd.css :root · 두 어두운 테마 블록) 값을 옮겼다(디자인 개편 v0.3 · 청록 강조 · graphite)
fonts/             글꼴 KMD Sans 사본(app/fonts · 앞 파일 512KB + 뒤 파일 unicode-range · SIL OFL 1.1 LICENSE.txt) · 사이트가 정적이라 사본을 둔다
favicon.svg        제품 로고 마크 사본(app/favicon.svg 와 같은 파일 · 머리 로고는 app/logo.js 의 마크 + 글자표)
demo/content.mjs   시험 지식(문서 4 · 항목 12)과 줄거리 6걸음 · 사람 김(지식관리자) · test-lee(인사팀) · test-park(IT 지원)
demo/run.mjs       세우기 → 저장 제안 · 승인 · 들이기 → 화면 찍기(라이트 · 다크 · 1280×800) → data/story.js(그래프 · 문서 · 기록 자료)
shots/             찍은 화면 <이름>-<light|dark>.png(home · kn · doc · item · rec · recs · search · cmd · edit · propose · graph · history · check · import · shape · seed)
data/story.js      run.mjs 가 만든다 · 손으로 고치지 않는다
```

```bash
node site/demo/run.mjs              # 다 하기(Chrome 또는 Edge 필요)
node site/demo/run.mjs --no-shots   # 자료만
```

## 줄거리(한 가닥이 한 주 동안 이어진다)

월요일 결정 「노트북을 입사 전날 집으로」 가 계정 · VPN · 첫날 일정 · 받는 법 · 돌려주는 법으로 번진다. 걸음마다 `why`(앞 걸음과 잇는 말)가 사이트에 보인다. 기록은 서식 칸(요약 · 바뀐 것 · 까닭 · 근거)으로 쓴다.

| 날 | 채널 | 누가 | 기록 → 항목 |
|---|---|---|---|
| 월 | 세션(Claude Code · kmd-team-save) · 저장 제안 → 승인 | test-lee | 「노트북은 입사 전날 집으로」 → 노트북 받기 · 입사 전날 |
| 화 | 자동수집(git 커밋 · 팀 일꾼 · 무인) | test-park | 「메일 계정은 입사 전날 밤 자동으로」 → 메일 계정 |
| 수 | 수기수집(파일 · 팀 일꾼 · 무인) | test-park | 「VPN 신청 안내.docx」 → VPN 신청 · IT 지원 포털(두 문서를 잇는다) |
| 목 | 화면 고치기 · 저장 확인 창 → [넣기] | 김 | 첫날 일정: 오후 팀 소개 → 오전으로 |
| 금 | 공유(개인 → 팀 · 보내기 확인 창 = 팀 저장 제안) | test-lee | 「노트북 택배 받은 뒤」 → 노트북 받기(같은 항목에 기록 둘) |
| 금 | 세션 · **받아들인 경고** | test-park | 「노트북 반납: 디스크 지우기」, 저장 제안에 「근거에 없는 값: 3일」 경고 → 승인 |

## 마디

| 마디 | 도식 | 움직임 |
|---|---|---|
| 첫 화면 | 한 줄 · 문서 화면 그림(세 칸 책상) | 없음 |
| 한눈에 | 네 단계 띠: 들어온다 → 저장 제안 → 승인(사람) · 규칙 길(무인) → 기록과 문서가 같이 바뀐다 → 찾는다 · 입력 오류면 아무것도 쓰지 않고 고쳐 다시 | 없음 |
| 개념 | 세 층 · 지식 지도(문서 넷 · 항목 · 문서 링크 · 이번 주에 바뀔 항목 표시) · 기록 하나 → 항목 둘 | 흐르는 점선 |
| 한 주의 이야기 | 요일 시간 줄 · 채널 여섯 → 저장 문 → 기록 · 문서(입력 오류 출구는 점선) · 걸음마다 잇는 말 + 작은 지식 지도(지금 바뀐 곳 · 앞서 바뀐 곳 · 받아들인 경고) + 옛 값 → 새 값 + 들어간 길 + 화면 | 점이 길을 따라 흐름 · 요일 저절로 넘김(누르면 멈춤) |
| 찾아가기 | 길 띠(모든 지식 → 찾기 → 항목 → 기록 → 문서) + 걸음 목록 + 화면 | 그림 바꿈 |
| 그래프 | 시험 지식 그래프 · 둘러보기 일곱 걸음(노트북 받기 → 월요일 기록 → 계정 발급 · 화요일 커밋 → VPN · 수요일 파일 → 노트북 반납 · 받아들인 경고 → 전체) · 점을 누르면 이웃 한 겹 | 점이 피어나고 선이 그려짐 |
| Claude Code | brief → match → section → 일 → propose(【저장 제안】) → 승인 → save 띠 + 세션 재생 | 글자 치기 · 띠가 같이 켜짐 |
| 화면 · 시작하기 | 화면 16장(크게 보기 · 밝기 단추로 어두운 테마 그림) · 두 프로그램과 그 사이 길(공유 · 설치 한 줄) · 자리 표 | 없음 |

밝기는 시스템 따라 · 머리 단추로 바꾼다(이 브라우저에 `kmd-site-theme`). 그림도 라이트 · 다크로 바뀐다. 움직임 줄이기 설정이면 애니메이션 없이 끝 상태로.

## 남은 것

- 공개(Vercel 등)와 도메인은 사람이 정한다. 올릴 때는 `site/` 폴더를 그대로 정적으로 낸다(빌드 없음).
- 제품 화면이 바뀌면 `node site/demo/run.mjs` 로 다시 찍고 PNG 를 넘겨 본 뒤 커밋한다. 제품 토큰이 바뀌면 site.css 머리 토큰도 다시 옮긴다.
