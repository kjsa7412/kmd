# 게이트웨이 설계서

문서 번호 GW-DS-001 · 판 v0.4 · 작성 설계팀

## 개정 이력

| 판 | 내용 |
|---|---|
| v0.3 | 테이블 gw_log 더함 |
| v0.4 | 버퍼 더함 |

## 1. 수집기

수집기는 PLC 에서 값을 읽어 묶음으로 만들어 전송기에 넘기는 프로세스다. 장비마다 하나씩 뜬다.

| 설정 | 값 |
|---|---|
| 전송 주기 | 5초 |
| 재시도 | 3회 |
| 읽기 시간 초과 | 3초 |

## 2. 전송기

전송기는 수집기가 넘긴 묶음을 중앙 서버로 보내는 프로세스다. 서버가 받지 못하면 묶음을 디스크 큐에 둔다.

| 설정 | 값 |
|---|---|
| 시간 초과 | 20초 |
| 큐 한도 | 500 묶음 |

## 3. 테이블 gw_log

게이트웨이가 보낸 묶음의 결과를 한 줄씩 남기는 테이블이다.

| 컬럼 | 형 | 뜻 |
|---|---|---|
| log_id | bigint | 줄 번호 |
| sent_at | timestamp | 보낸 때 |
| batch_no | int | 묶음 번호 |
| result | char(1) | S 성공 · F 실패 |
| retry_cnt | int | 다시 보낸 수 |

## 4. 버퍼

버퍼는 수집기와 전송기 사이에서 보낼 묶음을 메모리에 담아 두는 모듈이다. 가득 차면 가장 오래된 묶음부터 디스크 큐로 내린다.

| 설정 | 값 |
|---|---|
| 내림 기준 | 80% |
