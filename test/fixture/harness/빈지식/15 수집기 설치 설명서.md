# 수집기 설치 설명서

수집기는 PLC 에서 값을 읽어 묶음으로 만드는 프로세스다. 장비 옆의 산업용 PC 에 설치한다.

## 설치

1. 설치 꾸러미 collector-setup.tar 를 /opt 에 푼다.
2. /opt/collector/collector.conf 를 연다.
3. PLC 주소와 포트를 적는다.
4. 전송기 주소를 적는다.
5. install.sh 를 관리자 권한으로 돌린다.
6. systemctl enable collector 로 켜 둔다.
7. systemctl start collector 로 띄운다.
8. 상태 화면에서 값이 오는지 본다.

## 설정

| 설정 | 값 |
|---|---|
| 전송 주기 | 5초 |
| 재시도 | 3회 |
| 버퍼 크기 | 1000 |
| 포트 | 502 |
