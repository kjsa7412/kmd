# 배포절차

DPMS 를 운영에 올리는 차례 — 팀이 같이 본다.

## 준비
<!-- applied: 2026-1021-배포-창 -->
배포 창은 화 · 목 14:00 ~ 17:00 이다. DB 커넥션 풀은 40 으로 둔다.
이미지 이름은 날짜-순번으로 짓는다(예 1022-01).

## 카나리
<!-- applied: 2026-1017-카나리 -->
`canary-1` 에 먼저 올리고, 첫 30분은 요청의 10% 만 보낸다. 오류율이 1% 를 넘으면 멈추고 롤백으로 간다.

## 헬스 체크
<!-- applied: 2026-1021-헬스-체크 -->
각 서버의 `/health` 를 30초마다 부른다. 시간 초과는 3초 — 3초 안에 200 이 와야 통과. 배포 뒤 서버 상태는 이것으로 본다.

## 롤백
DB 를 먼저 되돌리고, 그다음 앱을 이전 판으로 내린다. 자세히는 [롤백 절차](롤백절차.md).

## 꾸러미 판
