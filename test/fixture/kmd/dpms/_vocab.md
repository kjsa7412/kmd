# 이름 장부

같은 것을 가리키는 이름 중 하나를 정하고 나머지를 다른 이름으로 잇는다.

## proc

- `proc:준비` — 준비
- `proc:카나리` — 카나리
- `proc:헬스 체크` — 헬스 체크
  aliases: 상태 점검
- `proc:롤백` — 롤백
- `proc:되돌리기` — 되돌리기
- `proc:되돌린 뒤 확인` — 되돌린 뒤 확인
- `proc:매일 백업` — 매일 백업
- `proc:복구 점검` — 복구 점검
- `proc:처음 10분` — 처음 10분
- `proc:연락 순서` — 연락 순서
- `proc:배포 승인` — 배포 승인

## screen

- `screen:서버 상태` — 서버 상태
- `screen:대시보드` — 대시보드
- `screen:경보 기준` — 경보 기준

## api

- `api:/health` — /health
- `api:/metrics` — /metrics

## term

- `term:알람` — 알람
- `term:꾸러미 판` — 꾸러미 판
- `term:운영 서버` — 운영 서버
- `term:점검 시간` — 점검 시간
- `term:보관 기간` — 보관 기간
- `term:디스크 점검` — 디스크 점검
- `term:VPN` — VPN

## table

- `table:배포 이력` — 배포 이력
- `table:서버 이력` — 서버 이력
