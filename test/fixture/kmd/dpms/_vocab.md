# 항목 장부

항목마다 `종류:값` 하나를 정하고 같은 것을 가리키는 다른 말은 별칭으로 잇는다.

## proc

뜻: 운영 · 배포에서 차례대로 하는 일 하나

- `proc:준비`: 준비
  gist: 배포 창 · 커넥션 풀 · 이미지 이름처럼 배포 전에 맞춰 둘 것
- `proc:카나리`: 카나리
  gist: 새 판을 서버 하나에 먼저 올려 요청 일부로 보는 단계
- `proc:헬스 체크`: 헬스 체크
  aliases: 상태 점검
  gist: 서버마다 상태 주소를 불러 살아 있는지 보는 점검
- `proc:롤백`: 롤백
  gist: 배포가 잘못됐을 때 DB 와 앱을 이전 판으로 돌리는 차례
- `proc:되돌리기`: 되돌리기
  gist: 이전 이미지로 내리고 DB 를 되돌리는 롤백 절차의 본 단계
- `proc:되돌린 뒤 확인`: 되돌린 뒤 확인
  gist: 롤백한 뒤 서버 상태를 다시 보는 마무리 단계
- `proc:매일 백업`: 매일 백업
  gist: DB 를 날마다 정한 시각에 떠 두는 백업
- `proc:복구 점검`: 복구 점검
  gist: 백업으로 실제 복구가 되는지 주기적으로 해 보는 점검
- `proc:처음 10분`: 처음 10분
  gist: 장애가 의심될 때 맨 먼저 할 일의 차례
- `proc:연락 순서`: 연락 순서
  gist: 장애 때 누구에게 어떤 차례로 알리나
- `proc:배포 승인`: 배포 승인
  gist: 운영 배포를 누가 언제까지 허락하나

## screen

뜻: 운영 대시보드의 화면 하나

- `screen:서버 상태`: 서버 상태
  gist: 서버마다 정상 · 주의 · 장애를 색으로 보이는 첫 화면
- `screen:대시보드`: 대시보드
  gist: 응답 시간 · 오류 수 · 디스크를 한 장에 모은 화면
- `screen:경보 기준`: 경보 기준
  gist: 경보가 울리는 응답 시간 · 오류율 문턱

## api

뜻: 서버가 내놓는 주소 하나

- `api:/health`: /health
  gist: 서버가 살아 있으면 200 을 돌려주는 상태 주소
- `api:/metrics`: /metrics
  gist: 응답 시간 같은 지표를 모아 내놓는 주소

## term

뜻: 운영에서 쓰는 말 하나의 뜻

- `term:알람`: 알람
  gist: CPU 같은 값이 문턱을 넘을 때 운영 채널로 가는 알림
- `term:꾸러미 판`: 꾸러미 판
  gist: 운영 서버에 깔린 라이브러리마다의 판
- `term:운영 서버`: 운영 서버
  gist: 실제 사용자 요청을 받는 서버 묶음
- `term:점검 시간`: 점검 시간
  gist: 서비스를 멈추고 손보는 정기 시간대
- `term:보관 기간`: 보관 기간
  gist: 로그를 지우지 않고 두는 날 수
- `term:디스크 점검`: 디스크 점검
  gist: 로그 디스크가 얼마나 찼는지 날마다 보는 일
- `term:VPN`: VPN
  gist: 운영 서버에 닿기 위해 거치는 사내 망
