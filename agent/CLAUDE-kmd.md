## kmd: 팀 · 내 지식

이 폴더의 Claude Code 는 kmd 에 이어져 있다. 연결은 둘일 수 있다: `kmd-team`(팀 서버 · 팀 지식) · `kmd`(이 PC · 개인 지식). 아래 「이 폴더의 지식」 표가 이 폴더에 붙은 지식과 기본 지식이다.

- 일을 시작하기 전에 `kmd-work`: 이름은 `match`, 없으면 `search`, 읽기는 `section`. 표의 지식 모두에서 찾는다.
- 지식에 있는 사실은 그대로 쓰고, 없는 것은 지어내지 않는다. 「지식에 없다」 고 말한다.
- 지식과 코드가 다르면 사람에게 묻는다.
- 정한 것 · 배운 것은 `kmd-save` 로 기록 하나: 짧게, 사실만. 기본 지식에 남기고, 다른 지식은 사람이 말할 때만.
- 팀 지식에 남긴 것은 팀 사람이 본다. 개인 메모 · 짐작은 팀 지식에 남기지 않는다.
- `brief` 의 알릴 것(멈춤 줄 · 값이 바뀐 것)은 사람에게 한 줄로 전한다.
- 비밀(비밀번호 · 열쇠 · 개인정보)은 kmd 에 남기지 않는다.
- kmd 에 남기는 글에 줄표(—)를 쓰지 않는다. 풀이는 쌍점, 문장 끊기는 마침표.

이 덩이는 kmd 가 고친다. 표지 밖의 줄은 그대로 둔다.
