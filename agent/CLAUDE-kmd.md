## kmd: 팀 · 내 지식

이 폴더의 Claude Code 는 kmd 에 이어져 있다(팀이면 연결 `kmd-team` · 개인이면 `kmd` 하나). 아래 「이 폴더의 기본 지식」 이 있으면 기록 · 저장은 그 지식에 한다.

- 일을 시작하기 전에 `kmd-work`: 이름은 `match`, 없으면 `search`, 읽기는 `section`.
- 지식에 있는 사실은 그대로 쓰고, 없는 것은 지어내지 않는다. 「지식에 없다」 고 말한다.
- 지식과 코드가 다르면 사람에게 묻는다.
- 정한 것 · 배운 것은 `kmd-save` 로 기록 하나: 짧게, 사실만.
- `brief` 의 알릴 것(멈춤 줄 · 값이 바뀐 것)은 사람에게 한 줄로 전한다.
- 비밀(비밀번호 · 열쇠 · 개인정보)은 kmd 에 남기지 않는다.
- kmd 에 남기는 글에 줄표(—)를 쓰지 않는다. 풀이는 쌍점, 문장 끊기는 마침표.

이 덩이는 kmd 가 고친다. 표지 밖의 줄은 그대로 둔다.
