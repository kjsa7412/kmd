## kmd: 개인 지식

이 폴더의 Claude Code 는 이 PC 의 개인 프로그램 kmd 에 이어져 있다(연결 `kmd`). 아래 「이 폴더의 개인 지식」 표가 이 폴더에서 읽고 남기는 개인 지식이다. 여기 남긴 것은 나만 본다.

- 일을 시작하기 전에 `kmd-work`: 이름은 `match`, 없으면 `search`, 읽기는 `section`. 표의 개인 지식 모두에서 찾는다.
- 지식에 있는 사실은 그대로 쓰고, 없는 것은 지어내지 않는다. 「지식에 없다」 고 말한다.
- 지식과 코드가 다르면 사람에게 묻는다.
- 정한 것 · 배운 것은 `kmd-save` 로 기록 하나: 짧게, 사실만. 표의 개인 지식이 여럿이면 남기기 전에 어느 지식에 남길지 묻는다.
- 이 폴더에 팀 지식(연결 `kmd-team`)도 붙어 있으면: 사람이 팀인지 개인인지 말하지 않은 「남겨」 는 어디에 남길지 묻는다.
- `brief` 의 알릴 것(멈춤 줄 · 값이 바뀐 것)은 사람에게 한 줄로 전한다.
- 비밀(비밀번호 · 열쇠 · 개인정보)은 kmd 에 남기지 않는다.
- 항목 글은 본문만(확정된 지금): 기록 링크 · `**경과**` 목록 · `<!-- -->` 주석은 넣지 않는다. 출처는 kmd 가 문서 끝 참고에 단다.
- kmd 에 남기는 글에 줄표(—)를 쓰지 않는다. 풀이는 쌍점, 문장 끊기는 마침표.

이 덩이는 개인 프로그램이 고친다. 표지 밖의 줄은 그대로 둔다.
