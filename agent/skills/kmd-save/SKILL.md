# kmd 에 남기기

1. 무엇을 남길지 한 줄 제목으로 — 「무엇 — 어떻게」 (예: 「카나리 — 첫 30분 20%」).
2. 건드린 이름을 `match` 로 맞춰 `touches` 에 넣는다. 맞는 이름이 없으면 비워 둔다(정리 때 kmd 가 찾는다).
3. `save` 하나로 보낸다 — 글은 사실만, 짧게. 누가 · 왜 정했는지 알면 같이.
4. 항목 글을 바로 고칠 수 있는 사람(주인 · 정리하는 사람)이면 `sections` 로 그 항목의 새 글을 같이 보낸다. 아니면 기록만 — 정리 때 문서에 들어간다.
5. 응답의 warnings(백업 멈춤 등)는 사람에게 그대로 전한다.

비밀(비밀번호 · 열쇠 · 개인정보)은 남기지 않는다.
