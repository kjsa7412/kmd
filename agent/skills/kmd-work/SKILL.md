# kmd 로 일하기

1. 처음 한 번 `brief` — 이 kmd 의 지식 목록과 알릴 것(멈춤 줄 · 값이 바뀐 것)을 본다. 알릴 것이 있으면 사람에게 한 줄로 전한다.
2. 일에 나오는 이름(테이블 · 화면 · API · 절차 · 용어)을 `match` 로 맞춘다 — 딱 맞는 이름이 있으면 그 항목을 쓴다.
3. 이름이 없으면 `search` 로 찾는다. 찾은 것은 짐작이 아니다 — `section` 으로 그 항목 글을 읽고 그대로 쓴다.
4. 글이 지식과 다르면 지식이 맞다고 보지 말고 사람에게 묻는다(코드가 바뀐 것일 수 있다).
5. 지식에 없는 것을 지어내지 않는다. 「지식에 없다」 고 말한다.

일이 끝나면 `kmd-save` 로 배운 것 · 정한 것을 남긴다.
