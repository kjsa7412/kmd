2말

지식

폴더 하나 · git 저장소 하나. 팀 지식(팀 서버) · 개인 지식(내 PC).

문서 · 항목

문서는 docs/**.md 한 파일, 항목은 그 안의 ## 머리 한 덩이. 정리 · 링크 · 출처의 단위.

이름

종류:값(예 table:tb_user). 이름 장부 · 자리 장부가 이름 → 항목을 잇는다.

기록

work/<id>.md. 사람 · 세션 · 파일 · 코드 묶음이 남긴 글. 바뀐 것 · 까닭 · 영향 · 근거 · touches.

정리

기록을 문서의 항목에 넣는 일. 승인 없이 검사 뒤 넣고, 줄마다 되돌린다.

자리

사람이 지식 하나에 갖는 권한. 받지 않은 지식은 「없음」 이 기본.

일 줄

가져오기 · 정리 일감이 차례로 선다. 수집 › 검토 › 기록 생성 › 문서 생성.

기기 열쇠

PC 마다 사람 이름으로 만든 열쇠. Claude Code 연결과 지식 보내기가 쓴다. 내 기기에서 끊는다.

화면 말은 디자인 컨벤션 9절의 용어집을 따른다: 「개인 프로그램」 · 「팀 프로그램」 · 「반영 대기 n」 · 「출처」 · 「총괄 관리자」 · 「취소」(창 닫기) / 「잠깐 멈춤」(이어 할 수 있음) / 「그만두기」(도는 일을 끝냄).

3지식의 모양

<지식>/ README.md # 지식 이름 docs/**.md 문서 · 항목 = ## 머리 … 끝에 <!-- kmd:참고 --> 블록 docs/assets/ 첨부 · 넣은 원본 work/<id>.md 기록 _vocab.md 이름 장부 _managed.md 자리 장부 _forms.md 갈래 장부 _members.md 주인 · 자리 · 정리 설정 _sources.json 가져올 곳 .git/ 저장마다 한 묶음 <지식 폴더>/.kmd/ 살림 자리 auth.json · auth.log · owners.json secrets.json · jobs.json · 색인
본문에는 확정된 지식만

경위 · 초안 · 아직 넣지 않은 기록은 본문에 두지 않는다. 시스템 참고 정보는 문서 끝 참고 블록과 표지 셋(applied · watched · baseline)에만.

쓰는 길은 하나

core/save.js: 기록은 늘 남고 · 같은 지식의 저장은 한 줄로 서고 · 실패하면 되돌린다. 문서를 쓰는 모든 길이 저장 검사(E_FORMAT)를 거친다.

링크는 셋

문서 x.md · 항목 x.md#머리 · 바깥 https://…. 기록 링크(work/)와 시스템 주소는 본문에 두지 않는다.

10지키는 것

비밀

셸 숨김 입력 · secrets.json 에만. 화면 · 로그 · 응답에 0.

비밀번호

브라우저가 미리 해시 · 서버는 scrypt · 여러 번 틀리면 잠시 막힘 · 위험한 일은 한 번 더(15분).

기기 열쇠

Windows 자격 저장소(%USERPROFILE%\.kmd\keys) · 헤더 도우미로만 꺼낸다 · 내 기기에서 끊기.

요청

다른 곳의 화면에서 온 쓰기는 받지 않는다 · 서버가 그리는 페이지는 CSP default-src 'none'.

파일

장부 · 설정은 임시 파일 뒤 이름 바꾸기 · 깨진 파일을 빈 것으로 덮지 않는다.

바깥

DB 는 읽기 전용 세션 · 카탈로그만 · GitLab 봇은 만들기 권한만 · 「Claude 쓰지 않음」 지식은 Claude 에 안 간다.
