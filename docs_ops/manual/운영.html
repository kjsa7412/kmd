총괄 관리자개인 프로그램을 쓰는 사람

운영 · 되살리기

저절로 도는 것, 밤 묶음, 무엇이 없어졌을 때 되살리는 길, 새 판으로 올리는 길이다. 명령은 kmd 를 띄운 자리(팀 서버는 그냥 kmd)에서 친다.

1늘 하는 것: 저절로

백업

지식마다 붙인 git 백업 자리로 저장 뒤 바로. 안 되면 1 · 5 · 15 · 60분 · 매일 다시. 6시간 밀리면 노랑 · 24시간이면 빨강 한 줄.

GitLab 봇

팀 서버 · 쓰면. 백업 자리가 없는 지식마다 그룹 안에 저장소를 찾거나 만들어 붙인다. 봇 열쇠는 만들기 권한만. 열쇠는 kmd secret set gitlab 로만.

DB 가져오기

어떤 계정이든 세션을 읽기 전용으로 열고 카탈로그만 읽는다(행은 읽지 않는다). 비밀번호는 비밀에만.

이 PC 늘 켜기

kmd pc task 한 번. 로그온 때 kmd up --no-open · 멈추면 1분마다 다시 켠다(작업 이름 kmd).

2밤 묶음(팀 서버)

지식 폴더는 백업 자리가 지킨다. 살림 자리(/srv/kmd/.kmd: 명부 auth.json · auth.log · 주인 · 상태 · 비밀)는 따로 묶는다.

tar -czf /backup/kmd-data-$(date +%F).tgz -C /srv/kmd .kmd
  • kmd 가 돌고 있어도 묶어도 된다. auth.log 는 따로 한 벌 더(다른 디스크). 되살릴 때 명부보다 늦은 일을 다시 적용한다.
  • 비밀(.kmd/secrets.json)이 든다. 묶음 자리는 관리자만 읽게 둔다.

3되살리기

무엇이 없어졌나하는 것
지식 하나(폴더가 깨짐 · 지움)kmd restore <백업 주소> <지식>: 새 폴더로 받아 fsck · 검사 · _members.md 로 주인 · 자리 · 정리 설정을 다시 건다. 원래 이름이면 같은 백업 자리로 이어 보낸다. 도는 팀 서버에는 [동기화] 로 목록에 선다
새 PCkmd 를 깔고 개인 화면 › 설정 › 일반 › [백업에서 되살리기](주소 · 이름), 또는 지식마다 kmd restore <백업 주소>
백업과 갈라졌다관리 화면에서 [이 백업 이어 쓰기](서버에만 있던 기록 · 문서를 먼저 보인다 · 지금 머리는 가지 kmd-before-<시각> 로 남는다) 또는 [서버 것으로 백업 덮기]
백업이 앞섰다[백업에서 받기]: 앞으로만 · 받은 글에 새 오류면 되돌린다
살림 자리 전부밤 묶음을 풀고 → kmd auth reapply <따로 둔 auth.log>. 끊은 기기 · 기계 열쇠는 다시 끊기고, 늦게 바꾼 비밀번호의 사람은 「다시 정하기」 링크를 새로 받는다
되살린 지식의 정리

_members.md 에 정리 설정 줄이 없는 옛 백업이면 「손으로만 · Claude 에 보내지 않음」 으로 두고 주인에게 알린다. 확인한 뒤 지식관리자가 정리 방식을 다시 고른다.

4되살리기 연습: 석 달에 한 번

  1. 읽기만 사본으로 받는다kmd restore <백업 주소> 연습 --root D:\연습 --practice. 연습 사본은 원래 백업에 붙이지 않는다(붙이면 연습 사본의 저장이 운영 백업으로 밀린다).
  2. 화면으로 연다문서 · 첨부 그림 · 항목 이름이 보이는지 본다.
  3. 값을 견준다원래 지식과 되살린 것의 git rev-parse HEAD^{tree} 가 같은지 본다.
  4. 연습 폴더를 지운다

5새 판

팀 서버

  1. 도는 일을 본다/srv/kmd/.kmd/jobs.json 에 도는 가져오기 · 정리가 있으면 끝나기를 기다리거나 일 줄을 멈춘다.
  2. 새 팀 꾸러미를 풀고 설치를 다시 돌린다sudo sh kmd-install.sh --team …(처음과 같은 인자). /opt/kmd 의 코드만 새 것으로 바꾸고 kmd.service · kmd-worker.service 를 다시 켠다(지식 · 살림 자리는 그대로).
  3. 확인한다curl <팀 주소>/healthz 의 build 가 새 판인지 · 화면 오른쪽 아래 판 · 관리 화면 문제 줄.

꾸러미 안의 새 PC zip 이 받기 자리에 놓인다. 설치 한 줄은 서버와 같은 판의 PC zip 을 먼저, 없으면 가장 높은 판을 준다.

이 PC

보통은 팀 화면 › 개인 프로그램 설치의 한 줄을 다시 붙인다. 이 PC 의 판(~/.kmd-app/current.json)과 팀 서버의 PC 꾸러미 판을 견주어 옛 판일 때만 올린다. 이미 깐 PC 는 저절로 바뀌지 않는다.

versions/<판>새 판을 옆에 둔다
›
켜 보기빈 폴더에서 healthz
›
실행기 바꾸기current.json · bin\kmd.cmd
›
다시 켜기안 되면 앞 판으로

손으로는 kmd pc update <새 판 폴더> <판>. 앞 판 폴더는 지우지 않는다. 되돌리려면 kmd pc update "%USERPROFILE%\.kmd-app\versions\<앞 판>" <앞 판>. 꾸러미 판 이름은 <판>-<날짜>-<시각>(kmd --version).
