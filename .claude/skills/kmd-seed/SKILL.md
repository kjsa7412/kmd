# kmd-seed: 짜임 꾸러미 만들기

바탕 세우기(빈 지식에 갈래 · 문서 · 항목 · 장부를 처음 세우는 일)의 **재료를 세션에서 만든다**. 화면은 한 번 300 파일 · 200MB 까지 열고 스캔을 글로 바꾸지 않는다. 그보다 큰 원본 · 스캔은 이 스킬이 꾸러미 폴더로 만들고, 사람이 그 꾸러미를 기초 세우기 화면에서 열어 승인하고 넣는다.

근거: [바탕 세우기 설계](../../../docs/품질개선/KMD_바탕세우기_설계.md) 6절(세션 입구) · 6-1(판단 기준) · 3-3(구조안 꼴). 쓰는 길은 `scripts/kmd-seed.mjs` 하나다(core/survey.js · core/shape.js planCheck 를 부른다).

```
① 조사      survey <원본> --out <꾸러미>        파일마다 글로 바꿈 · 판 · 같은 글 · 스캔 · 비밀 의심 · 처음 고르기
② 스캔 글   원본을 읽어 글을 짓고 text 로 넣음    글 층이 없는 pdf · 그림만 든 문서
③ 카드      하위 에이전트(prompt card)            재료마다 대상 · 갈래 · 장부에 올릴 만한 것 · 확정 사실
④ 구조안    하위 에이전트(prompt plan) → check    plan.json(kind seed) · 걸림 0 까지
⑤ 글 초안   (선택) 하위 에이전트(prompt text)     texts/<문서>.json · check 로 꼴 검사
⑥ 넘기기    사람이 기초 세우기 화면에서 꾸러미를 열어 승인 · 넣기
```

## 도구

kmd 저장소(또는 설치된 판 폴더 `~/.kmd-app/versions/<판>`)에서:

| 명령 | 하는 일 |
|---|---|
| `node scripts/kmd-seed.mjs survey <원본> --out <꾸러미>` | 조사. 꾸러미 폴더는 빈 폴더이거나 앞 꾸러미여야 한다(지식 폴더 · 원본 자신 · 다른 것이 든 폴더는 거절). 다시 돌리면 넣어 둔 스캔 글을 이어 쓴다 |
| `node scripts/kmd-seed.mjs text <꾸러미> <원본 경로> <글.md>` | 스캔 글 넣기(그 줄이 재료가 됨 · `scan: true` · 고르기 넣음) |
| `node scripts/kmd-seed.mjs prompt <꾸러미> card [--from n] [--n 10] [--save]` | 카드 일감 프롬프트(재료 10개씩) · `--save` 면 꾸러미 `prompts/card-<n>.md` 에 쓰고 경로 한 줄만 |
| `node scripts/kmd-seed.mjs prompt <꾸러미> plan [--save]` | 구조안 일감 프롬프트(`--save` 면 `prompts/plan.md`) |
| `node scripts/kmd-seed.mjs prompt <꾸러미> text <문서 id> [--save]` | 글 초안 일감 프롬프트(작성기준 3 ~ 5절 · 좋은 예 · 나쁜 예 · `--save` 면 `prompts/text-<문서>.md`) |
| `node scripts/kmd-seed.mjs check <꾸러미> [--kn <지식 폴더>] [--json]` | 마른 검사(쓰지 않음): 구조안 꼴 · planCheck(G4 · 머리 · 갈래 · 장부 항목 자리 · 크기) · 재료 있음 · 덮임 · 비밀 의심 재료 · 글 초안 꼴. `--kn` 은 넣을 지식 사본을 읽기만 한다. 걸리면 나가는 코드 2 |
| `node scripts/kmd-seed.mjs status <꾸러미> [--json]` | 요약: 판 · 고르기 · 글 없는 스캔 · 카드 · 구조안 · 글 초안 · 문제 |

부르는 꼴(허락 규칙이 명령 앞머리로 맞춰 보므로 이 꼴이어야 사람 세션은 묻는 일이 줄고 무인 세션은 거절되지 않는다):

- 한 번에 명령 하나: `node <kmd 저장소>/scripts/kmd-seed.mjs <명령> …`. 지금 폴더가 저장소가 아니면 스크립트를 **절대 경로**로 부른다. `cd … &&` 를 앞에 붙이지 않는다.
- 파이프 · 돌려쓰기(`| head` · `2>&1`)를 붙이지 않는다. 출력이 길면 `--json` 으로 받거나 나온 파일을 Read 한다.
- 폴더를 만들거나 확인하지 않는다(`mkdir` · `ls` 없음 · `||` 없음). `survey` 가 `cards/` · `texts/` · `prompts/` 를 만들어 두고, 파일은 Write 로 쓰면 폴더가 따라 생긴다. 하위 에이전트 프롬프트(`prompt … --save`)도 `check` 를 절대 경로 한 줄로 싣는다.
- 명령이 거절되면 멈추지 말고 위 꼴(절대 경로 · cd 없이 · 파이프 없이)로 다시 부른다.

## 꾸러미 꼴

| 파일 | 무엇 | 누가 쓰나 |
|---|---|---|
| `manifest.json` | `{ v: 1, kind: "kmd-seed", made, root, counts, rows }` · 줄마다 `path · size · orig(원본 지문) · src(m:<16자>) · role · pick · digest · secret? · scan?` | survey · text 만(손으로 고치지 않는다) |
| `md/<16자>.md` | 재료 글. 이름이 지문이라 고치면 check 가 「지문이 다르다」 로 걸린다 | survey · text 만 |
| `cards/<16자>.json` | 재료 카드 하나 | 카드 하위 에이전트 |
| `plan.json` | 구조안(설계 3-3 · `kind: "seed"` · 문서마다 `was: null` · 항목마다 `src`) | 구조안 하위 에이전트 · 고칠 때 이 세션 |
| `texts/<문서>.json` | `{ doc, items: [{ h, text }] }` 항목 글 초안(있으면 화면의 짓기가 Claude 대신 이 글로 시작) | 글 하위 에이전트 |

`role`: 정본 · 옛 판 · 같은 글 · 스캔 · 비밀 의심 · 그림 · 못 읽음. `pick`(처음 고르기): 정본 넣음 · 옛 판 빼기 · 같은 글 빼기 · 스캔 보류(글을 넣으면 넣음) · 비밀 의심 보류 · 못 읽음 빼기. 고르기는 처음 값이고 사람이 화면에서 다시 고른다.

## ① 조사

1. 사람에게 원본 폴더와 꾸러미를 둘 곳을 묻는다. 꾸러미는 원본 밖 · 지식 폴더 밖의 빈 폴더다(예: `<원본>-꾸러미`).
2. `survey` 를 돌리고 나온 요약을 그대로 보인다: 원본 n 파일 · 크기 · 정본 · 옛 판 · 같은 글 · 스캔 · 비밀 의심 · 못 읽음.
3. **비밀 의심**(비밀번호 · 열쇠 꼴 줄 · 개인 열쇠 · 주민번호 꼴)은 보류다. 카드 · 구조안 프롬프트에 실리지 않는다. 파일 이름과 까닭(줄 번호)만 보이고 값은 옮기지 않는다.
4. 판 묶음이 이상하면(다른 대상이 한 묶음 · 같은 대상이 두 묶음) 사람에게 보이고, 화면의 걸러 두기에서 고치면 된다고 말한다. 꾸러미 manifest 를 손으로 고치지 않는다.

## ② 스캔 글

`status` 의 「글 없는 스캔 n」 이 대상이다. 파일마다:

1. 원본(pdf · 그림)을 Read 로 읽고 보이는 글을 그대로 md 로 옮긴다. 첫 줄은 `# <파일 이름(확장자 뺌)>`, 표는 md 표, 읽지 못한 칸은 `(읽지 못함)`. 값(수 · 날짜 · 이름 · 코드)은 글자 그대로. 요약하거나 고쳐 쓰지 않는다.
2. 비밀(비밀번호 · 열쇠 · 주민번호 · 계좌)은 옮기지 않고 `(가림)` 으로 쓴다.
3. 임시 파일(세션 스크래치)에 쓰고 `text <꾸러미> <원본 경로> <임시.md>` 로 넣는다.
4. 수가 많으면 하위 에이전트로 나눈다(파일 10개씩 · 같은 규칙을 프롬프트에).

## ③ 카드 · ④ 구조안 · ⑤ 글 초안

- **하위 에이전트 프롬프트는 한 줄**: `prompt … --save` 가 찍은 경로를 「<경로> 를 Read 하고 그대로 따른다」 로만 넘긴다. 프롬프트 글을 Agent 입력으로 옮겨 쓰지 않는다(수천 자를 다시 생성하느라 한 번에 30초 남짓 걸리고 그동안 다른 Agent 를 띄우지 못한다). 나란히 돌릴 Agent 들은 한 답에 함께 낸다.
- **카드**: `prompt card --from 0 --save`, `--from 10 --save`, … 의 경로를 하위 에이전트(Agent)에 넘긴다. 동시에 서너 개까지. 비밀 의심 · 빼기 재료는 프롬프트에 실리지 않는다. 카드에서 `secret: true` 가 나온 재료는 사람에게 알리고 화면에서 보류로 고르라고 말한다.
- **구조안**: 카드가 다 서면 `prompt plan --save` 의 경로를 하위 에이전트 하나에 넘긴다. 받은 `plan.json` 을 `check` 로 본다. 걸림이 0 이 될 때까지 고친다(에이전트에게 걸림 줄을 그대로 돌려 주거나 이 세션이 plan.json 을 고친다). 경고(문서당 항목 5~40 · 폴더당 문서 3~12 · base 없음)는 사람에게 보이고 넘어가도 된다.
- **글 초안**(선택 · 큰 지식에서 화면의 짓기를 줄이고 싶을 때): 문서마다 `prompt text <문서 id> --save` 의 경로를 하위 에이전트에 넘긴다(문서들의 Agent 는 한 답에 함께). 재료에 없는 값을 지으면 넣을 때 값 대조가 걸러 걸음 실패가 된다(아무것도 쓰지 않는다). 다 쓰면 `check` 로 꼴(머리 줄 · 주석 · 기록 링크 · 시스템 주소)을 본다.

판단 기준(설계 6-1 · 프롬프트에 그대로 실린다): 문서는 대상 하나 · 사건 갈래 하나 · 대장 하나. 파일 경계는 참고만. 문서 이름에 날짜 · 판 · 최종 · 확장자를 쓰지 않는다. 항목은 대상 하나의 지금이고 늦은 판이 이긴다. 모으는 문서는 되풀이되는 꼴마다 하나이고 처음 한 건으로도 선다(생성 룰 R3-2). 세우는 항목마다 장부 짝(names · 종류:값 · gist 뜻 한 줄 · R7-1 · 머리만 세우지 않는다). 새 문서마다 으뜸 성격(`nature` · R4-1). 폴더 깊이 2단 · 폴더당 문서 3~12 · 문서당 항목 5~40 · 항목 300줄 안. 넣음 재료는 모두 어느 항목의 `src` 이거나 `skip` 에 까닭과 함께. 항목 글은 [작성기준](../../../docs/kmd_문서_작성기준.md) 3 ~ 5절(본문만 · 확정된 것만 · 링크 세 꼴 · `##` · `<!-- -->` · 기록 링크 없음).

## ⑥ 화면으로 넘기기

`check` 가 걸림 0 이면 사람에게 끝 요약을 보인다: 원본 n · 재료 n(스캔 글 n) · 보류 n(비밀 의심 n) · 카드 n · 구조안 문서 n · 항목 n · skip n · 글 초안 n · 경고 줄. 그리고 넘기는 법을 말한다.

- **개인 지식**: 개인 프로그램 › 지식관리 › 기초 세우기에서 원본 칸에 **꾸러미 폴더 경로**를 넣는다. 걸러 두기부터 같은 승인 · 같은 엔진(연습 판 · 값 대조 · 걸음 실패)으로 간다. 꾸러미의 고르기 · 구조안은 처음 값이고 사람이 화면에서 승인한다.
- **팀 지식**: 팀 화면 지식관리 › 기초 세우기 올리기는 원본 파일을 한 묶음 300 파일 · 200MB 까지 받는다. 300 파일 안이면 꾸러미 `md/` 의 재료 글(스캔 글 포함 · 비밀 의심 뺌)을 올린다. 그보다 크면 팀 지식을 나눌지 사람과 정한다(이 스킬은 팀 서버에 보내지 않는다).

## 하지 않는 것

- 지식 폴더 · 서버 폴더에 직접 쓰기 · 손 Edit · git push · 승인 없이 넣기. 이 스킬은 꾸러미 폴더에만 쓴다.
- manifest · `md/` 를 손으로 고치기(지문이 깨진다: 다시 `survey` 나 `text`).
- 비밀 의심 재료를 하위 에이전트에 보내기 · 비밀 값을 대화 · 카드 · 글에 옮기기.
- 「Claude 에 보내지 않음」 지식의 바탕을 이 스킬로 짓기(재료 글이 이 대화 · 하위 에이전트로 간다). 사람에게 말하고 멈춘다.
- 원본 파일을 꾸러미에 복사하기(꾸러미는 글만 든다 · 원본은 제자리).

## 생성 룰

무엇이 항목이고 어느 문서에 두는지 · 성격과 종류 · 새 문서를 세울지는 고정 생성 룰(R1 ~ R9)로 정한다. 일을 시작할 때 `node scripts/kmd-seed.mjs rules` 로 조문을 읽고, 이 스킬 글의 다른 줄과 다르면 생성 룰을 따른다. 판단의 근거는 조문 번호로 적는다.
