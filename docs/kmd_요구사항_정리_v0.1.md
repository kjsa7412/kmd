# kmd 요구사항 정리 v0.1 — 개발 완료 뒤 운영자 요구(2026-10-23 ~ 24)

개발 완료(P5) 뒤 운영자가 요구한 수정을 한 장으로 모으고, 그 기준으로 **개인 서비스(이 PC 프로그램 · mode pc)** 와 **팀 서비스(팀 서버 · mode team)** 를 화면 · 동작까지 대조한 결과다. 화면 기준은 `docs/kmd_목업.html` · `kmd_목업_인터랙션.html` 이지만 **요구가 목업을 이긴다**(바뀐 것은 절차서 「나온 것」).

- 근거 — `git log`(2026-10-23 ~ 24) · `CHANGELOG.md` 「(다음 판)」 · `docs/kmd_개발절차_TODO.md` 「나온 것」 아래쪽 줄 · `docs/kmd_감시_검토_v0.1.md` §7 ~ §12.
- 대조 — `KMD_LOCAL_PORT=7391 node scripts/local.mjs`(팀 localhost:7391 · PC 127.0.0.1:7392 · 진짜 Claude) · 내장 브라우저 1300px · 760px · 420px. Claude 로그인 · 실제 Claude 부르기가 걸리는 일은 하지 않았다(사용자 몫).
- 상태 — **맞음**(요구대로) · **고침**(이번 대조에서 어긋나 고쳤다) · **남음**(아직 어긋나거나 운영자가 정할 것) · **모름**(이 PC 에서 볼 수 없다).
- 걸림 — 개인 = 이 PC 프로그램(과 팀 화면에서 연 내 PC 지식 · 팀 서버의 개인 지식) · 팀 = 팀 서버의 팀 지식.
