# kmd 설명서 — 쓰는 사람

kmd 는 팀과 내 PC 의 지식(문서 · 기록)을 한 곳에서 읽고, Claude Code 가 같은 지식으로 일하게 한다.

## 처음

1. 관리자에게 받은 **처음 들어오기 링크**를 연다 → 비밀번호를 정한다(브라우저가 제안하는 것을 쓰면 된다). 한 번 들어오면 일주일쯤 이어진다.
2. 비밀번호를 정한 그 화면의 **설치 한 줄 복사** → PowerShell 에 붙여 넣는다. 묻는 것 없이 끝나고 ✓ 넷이 찍힌다.
   - ✓ 세웠다 — 이 PC 의 내 지식 자리(D:\kmd)와 백업 자리
   - ✓ 팀에 이었다 — 내 이름으로
   - ✓ Claude Code 에 이었다 — 새로 여는 것부터
   - ✓ 늘 켜기 — PC 를 켜면 저절로
3. 「새 기기가 이어졌다」 줄이 내 「오늘 바뀐 것」 에 남는다. 내가 한 것이 아니면 [보기] 에서 끊는다.

## 보는 법 셋

- **문서** — 왼쪽 나무에서 문서를 연다. 탭 · 나란히 보기(Ctrl \\) · 글 속 항목 이름에 마우스를 올리면 미리보기.
- **항목** — 테이블 · 화면 · API · 절차 · 용어처럼 이름 있는 것 하나하나. 「이 항목을 쓰는 곳」 이 같이 보인다.
- **그래프** — 항목 · 문서 · 기록이 어떻게 이어졌나. 점을 누르면 이웃만.

빨리 열기 **Ctrl O** · 찾기 **Ctrl K** · 명령 창 **Ctrl P**.

## 고치기

- 문서 위 [고치기] → 저장. 내 지식이면 바로 문서에 들어간다.
- 팀 지식이면 **기록**으로 남고, 정해진 시각(보통 02:30)이나 누군가의 [지금 정리] 때 kmd 가 문서에 넣는다. 그동안도 문서 옆에 같이 읽힌다.
- 값이 바뀌면(예: 10% → 20%) 내 「오늘 바뀐 것」 맨 위에 노란 줄로 알린다. 줄마다 되돌릴 수 있다.
- 편집기로 md 파일을 직접 고쳐도 된다(이 PC) — 30초 조용하면 저절로 들어간다.

## 자료 가져오기

- **파일 · 폴더 넣기** — 끌어다 놓으면 문서가 된다. md · docx · pptx · xlsx 는 바로 바꾸고 원본은 첨부로 둔다. hwpx · pdf 는 원본만 먼저 첨부로. 한 번에 300 파일 · 200MB.
- **자동으로 가져오는 곳** — 코드 폴더 · git 주소를 한 칸에 붙이면 「꾸러미 판」 같은 표를 때마다 다시 채운다. 팀에서는 관리자가 더한다 — [관리자에게 부탁].

## 지식 추가 · 보내기

- **지식 추가** — 새 이름(나만 쓰는 지식) · 내 PC 폴더(그 자리에서 따라간다 · 복사하지 않는다) · 팀 지식 주소.
- **보내기** — 내 지식에 보낼 곳(팀 지식)을 정해 두면, 고친 문서가 보내기에 저절로 모인다. [N개 보내기] 를 누르면 팀 지식의 정리 때 들어간다. 팀 서버에 닿지 않으면 닿을 때 저절로 보낸다.

## 멈춤 한 줄

저절로 하는 일(백업 · 가져오기 · 정리)이 멈추면 맨 위에 한 줄이 선다 — 무엇이 · 얼마나 — 풀리는 길. 잘 될 때는 줄이 없다.

## 밖으로 나가는 것

보내기 · 백업 · Claude 정리뿐이다. 정리에 Claude 를 쓰지 않으려면 설정 › 저절로 하는 일에서 끈다.
