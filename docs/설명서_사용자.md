# kmd 설명서: 쓰는 사람

kmd 는 지식(문서 · 기록)을 읽고 고치며, Claude Code 가 같은 지식으로 일하게 한다. 프로그램은 둘이다.

- **팀 프로그램**(팀 서버 · 팀 화면): 팀 지식만. 아이디 · 비밀번호로 들어오고, 관리자가 자리를 준 지식만 보인다.
- **개인 프로그램**(내 PC 에 깐 kmd · 개인 화면): 내 개인 지식만. 나 혼자 쓰고 팀 서버에 가지 않는다.

두 화면은 서로를 부르지 않는다(브라우저의 다른 탭). 둘 사이에 남는 길은 Claude Code 세션의 연결 둘(`kmd-team` · `kmd`)과 **지식 보내기**(개인 → 팀, 개인 화면에서)뿐이다.

## 처음

1. 관리자에게 받은 **처음 들어오기 링크**를 연다 → 비밀번호를 정한다(브라우저가 제안하는 것을 쓰면 된다). 한 번 들어오면 일주일쯤 이어진다. 팀 화면에는 관리자가 자리를 준 팀 지식만 보인다. 보여야 할 지식이 없으면 관리자에게 묻는다.
2. 팀 화면의 **개인 프로그램 설치**(누구나)에서 **한 줄 복사** → PowerShell 에 붙여 넣는다. 10분 안에 한 번 쓴다. 설치 · 업데이트 · 팀에 잇기가 모두 이 한 줄이다(아래 「개인 프로그램 설치」).
   - 이 PC 에 kmd 가 없으면 팀 서버에서 PC 꾸러미를 받아 `%USERPROFILE%\.kmd-app` 에 깔고 사용자 PATH 에 `kmd` 를 더한다(관리자 권한 없이). 팀 서버에 꾸러미가 없으면 그렇다고 알린다. 관리자에게 묻는다.
   - 묻는 것 없이 끝나고 ✓ 넷이 찍힌다.
   - ✓ 세웠다. 이 PC 의 내 지식 자리(D:\kmd)와 백업 자리
   - ✓ 팀에 이었다. 내 이름으로(이 기기 열쇠로 Claude Code 가 팀 지식을 읽고, 지식 보내기가 팀에 보낸다)
   - ✓ Claude Code 에 이었다. 새로 여는 것부터
   - ✓ 늘 켜기: PC 를 켜면 저절로 켜고, 멈추면 다시 켠다. 끝에 **개인 화면**이 한 번 열린다. 지식 폴더 경로는 개인 화면 › 설정에서 바꾼다.
3. 「새 기기가 이어졌다」 줄이 내 「이력」 에 남는다. 내가 한 것이 아니면 개인 프로그램 설치 › 내 기기에서 끊는다.

## 개인 화면 열기

개인 프로그램(내 지식 · 파일 넣기 · 지켜보며 맞추기 · 지식 보내기 · 설정)은 아이디 · 비밀번호가 없다. 개인 프로그램이 여는 한 번용 주소로만 들어온다.

- **시작 메뉴 › kmd** 를 누른다. 꺼져 있으면 켜고 개인 화면을 연다. 터미널이면 `kmd open`.
- 한 번 들어온 브라우저는 쓰는 동안 이어진다(마지막으로 쓴 날부터 30일).
- 주소창에 이 PC 주소(`127.0.0.1:7373`)만 치거나 지난 주소를 열면 「개인 화면을 연다」 안내가 선다. 위처럼 다시 연다. 팀 화면의 아이디 · 비밀번호로는 들어오지 않는다.
- 팀 화면은 팀 주소를 브라우저로 따로 연다(즐겨찾기). 팀 화면은 개인 프로그램을 부르지 않는다.

## Claude 로그인(개인 프로그램)

개인 화면 › 설정 › **Claude 연결**: [Claude 로그인] 을 누르면 작업 표시줄에 **「kmd: Claude 로그인」 창**이 뜨고(`claude auth login`), 그 창이 브라우저를 연다. 브라우저에서 Claude 에 들어가면 끝: 이 화면이 몇 초마다 저절로 확인해 「로그인됨」 으로 바뀐다([지금 확인] 도 있다). Claude Code 의 로그인은 진짜 터미널이 있어야 돌아서 이 화면 안에 넣지 못한다. [로그인 확인] 은 아주 작은 부르기 한 번으로 지금 로그인이 살아 있는지 본다(`claude auth status` 는 끝난 로그인도 「됨」 이라 말한다). 로그인이 끝났거나 한도에 닿으면 이 칸이 알려 주고, 그동안 기록은 규칙으로 문서에 들어간다.

## 화면

- **왼쪽 위: 지식 고르기**: 지식을 고르고, 문서 · 항목 · 그래프 탭과 그 탭의 목록(나무)을 본다. 다른 화면에 가도 목록은 그대로 있다.
- **왼쪽 아래: 지식 관리**: 팀 화면이면 이력 · 가져오기(지식관리자) · 정리(읽기 이상이 보고 · 쓰기는 자기 기록만 · 남의 기록은 지식관리자) · 설정 / 개인 화면이면 이력 · 가져오기 · 지식 보내기 · 설정.
- **개인 프로그램 설치**(팀 화면 옆 메뉴의 별도 자리 · 누구나): 아래 「개인 프로그램 설치」 절.
- **팀 화면은 팀 지식만, 개인 화면은 개인 지식만** 다룬다. 팀 지식은 팀 서버에, 개인 지식은 내 PC 의 지식 폴더에만 있다(팀 서버에는 개인 지식이 서지 않는다). 개인 지식의 일(다듬기 · 변환 · 가져오기)은 개인 프로그램이 **내 Claude 로그인**으로 하고, 팀 지식의 정리는 팀 서버의 정리 전용 로그인(총괄 관리자가 해 둔다)으로 한다.
- 개인 프로그램은 다른 화면(팀 화면 · 다른 사이트)에서 온 요청을 받지 않는다. 개인 지식의 일은 모두 개인 화면에서 한다.
- **위 머리**: 가운데 빨리 열기 · 찾기, 오른쪽 설명서(새 탭: 이 설명서) · 나.

## 보는 법 셋

- **문서**: 왼쪽 문서 탭의 나무에서 문서를 연다. 탭 · 나란히 보기(Ctrl \\) · 글 속 항목 이름에 마우스를 올리면 미리보기.
- **항목**: 테이블 · 화면 · API · 절차 · 용어처럼 이름 있는 것 하나하나. 「이 항목을 쓰는 곳」 이 같이 보인다.
- **그래프**: 항목 · 문서 · 기록이 어떻게 이어졌나. 점을 누르면 이웃만.

빨리 열기 **Ctrl O** · 찾기 **Ctrl K** · 명령 창 **Ctrl P**.

## 고치기

- 문서 위 [고치기] → 저장. 내 지식이면 바로 문서에 들어간다.
- 팀 지식은 **지식마다 받은 자리**대로 한다(총괄 관리자 › 지식관리자 › 쓰기 › 읽기). 받지 않은 지식은 보이지 않는다.
  - **읽기**: 문서 · 기록 · 이력 · 그래프 보기 · 찾기. 고치기 · 파일 넣기 단추는 흐리게 「쓰기 자리가 없다」.
  - **쓰기**: 고친 것은 **기록**으로 남고, 그 지식의 정리 방식(정해진 시각: 보통 02:30 · 실시간 · 손으로만)대로 kmd 가 문서에 넣는다. 그동안도 문서 옆에 같이 읽힌다. 일 줄에 파일 · 폴더 넣기 · 가져오기 부탁 · 자기 기록 되돌리기도.
  - **지식관리자**(주인 포함): 고치면 바로 문서에 들어간다. 정리(남의 기록까지) · 되돌리기 · 가져올 곳 · 지금 가져오기 · 지식 설정 · 그 지식의 권한 주기.
  - **총괄 관리자**: 모든 지식이 보이고 모두 지식관리자다. 사람 · 팀 지식 세우기 · 백업 · Claude 연결도.
- 「나만」 은: 개인 지식은 내 PC 에만 있어 팀 서버 · 팀원 · 관리자 어디에도 가지 않는다. 팀으로 가는 것은 지식 보내기로 고른 기록 · 문서뿐이다.
- **개인 프로그램**은 정리가 따로 없다. 기록(세션이 남긴 것 · 화면에서 남긴 것 · 받은 것 · 소스 코드의 묶음 기록 · 넣은 파일)은 남는 즉시 kmd 가 문서에 넣는다. Claude 로 다듬어 넣고(검사를 넘을 때만), Claude 로그인이 없거나 검사를 못 넘으면 규칙으로: 항목이 정해진 기록은 그 항목 끝에 글을 붙이고, 이름 없는 기록은 새 문서로. 켤 때 쌓여 있던 기록도 넣는다. 넣은 일은 이력에.
- 값이 바뀌면(예: 10% → 20%) 내 「이력」 맨 위 「확인할 것」 에 노란 줄로 알린다. 줄마다 되돌릴 수 있다.
- 편집기로 md 파일을 직접 고쳐도 된다(개인 프로그램): 30초 조용하면 저절로 들어간다. kmd 가 꺼져 있던 동안 고친 것은 켤 때 거둔다. 기록(`work/`) · 이름 장부는 고치지 않는다. 고치면 kmd 가 되돌리고, 고친 글은 사본으로 남겨 「이력」 노란 줄로 사본 자리를 알린다.
- 고치는 창: [항목 더하기] · 항목을 지우려면 그 「## 」 줄과 글을 지운다 · 이름만 바꾸려면 「## 」 줄만 고친다(지우기 · 이름 바꾸기는 저장 전에 한 번 묻는다). **Ctrl S** 저장 · **Esc** 그만두기.
- 쓰던 글은 찾기를 열고 닫거나 다른 화면에 갔다 와도 그대로다. 창을 닫거나 새로 고치면 묻는다 · 저장하지 않고 닫았으면 다음 [고치기] 때 되살린다(이 탭 안에서). 들어온 것이 끝났으면(12시간 쉬었거나 7일) 저장할 때 그 자리에서 비밀번호를 묻고 이어서 저장한다.

## 가져오기(옛 자료 · 파일 · 폴더)

탭 셋: **일 줄** · **가져올 곳** · **끝난 일**.

- **일 줄**: 들여오는 일은 모두 여기에 선다: 넣은 파일 · 여러 파일 묶음 · 가져오기(문서 폴더 · git · DB) · 기록을 문서에 넣기 · (팀) 정리 일감. 도는 중 · 멈춤/확인할 것/못함 · 기다림(차례 번호)으로 나뉜다.
  - **네 단계**: 일은 늘 수집 › 검토 › 기록 생성 › 문서 생성. 줄의 작은 네 칸 막대가 지금 단계다. 줄을 누르면 오른쪽 자세히에 흐름 그림(단계마다 안의 걸음 · 걸린 시간) · 터미널 · 만든 것(문서 · 기록 · 이름). 흐름의 단계를 누르면 터미널에 그 단계의 줄만.
  - **손잡이**: [멈춤] 은 지금 단계를 마치고 선다 · [이어서] · [그만두기] 는 바로 끊는다(도는 Claude Code 를 끈다. 끝난 단계에서 남긴 기록은 그대로 · 정리 때 문서에 넣는다) · [다시] 는 못한 단계부터 · 기다리는 일은 [맨 앞으로] 와 끌어서 순서 바꾸기 · [빼기]. 넣은 사람 · 지식관리자가 한다(개인 프로그램은 나).
  - **확인할 것**: 가져오기가 한꺼번에 크게 바뀌어(사라짐이 많다) 쓰지 않고 멈췄다. [그대로 맞추기] 는 브레이크를 넘어 원본대로 쓴다(이력에서 되돌릴 수 있다) · [이번은 건너뛰기] 는 다음 정한 때에 다시 본다.
  - **줄 멈춤**: 도는 일은 다음 단계 앞에서 서고 기다리는 일은 시작하지 않는다(정한 때 · 실시간으로 오는 일도 줄에만 선다). [줄 다시 돌리기] 로 잇는다. **동시에 도는 수**: Claude(문서 생성) 기본 1 · 가져오기 기본 2 · 일 줄 머리에서 1~4. 팀에서는 둘 다 총괄 관리자가.
  - 다시 켜도 일 줄은 남는다. 꺼질 때 돌던 파일은 그 단계부터 다시, 멈춘 일은 멈춘 채로.
- **끝난 일**: 30일 동안 남는다(터미널 줄까지). 파일 · 제목으로 찾고 갈래 · 결과(끝남 · 그만둠 · 못함)로 거른다. 그만둔 일은 [다시].
- **파일 · 폴더 넣기**: 끌어다 놓으면 파일마다 **기록**이 된다(md · docx · pptx · xlsx · hwpx · hwp · pdf 는 kmd 가 글로 바꾸고: 목차 · 쪽 번호 · 되풀이 머리글 · 빈 열은 뺀다. 글이 없는 pdf(스캔) · 암호 · 배포용 파일과 글 없이 그림만 든 docx · pptx(통그림 슬라이드)만 Claude Code 가 원본(오피스 파일은 안의 그림)을 읽어 글로 바꾼다 · 팀 서버에서는 「바꾸지 못한 파일」로 남고 빈 문서를 세우지 않는다 · 원본은 첨부로).
  - **받은편지함**(개인 화면): 넣을 지식을 고르지 않고 처음 파일을 넣으면 「받은편지함」 지식이 생긴다(나만). 이름이 걸리는 메모는 다른 개인 지식으로 옮긴다(받은편지함 정리). 태그 `private` 메모는 옮기지 않는다.
  - **세션처럼 들인다**. 파일마다 kmd 가 Claude Code 를 띄워 세션에서 일하듯 넣는다: 파일을 끝까지 읽고 → 지식을 둘러보고 → 글 속 이름(테이블 · 화면 · 절차 · 용어 …)을 맞추고 → 갈래 · 주제 문서의 항목으로 넣고(문서 이름은 파일 이름이 아니다. 회의 · 통화 파일은 회의록 › 「2026-10-21 HNC 통화: …」 · 파일 글은 Claude 가 다시 쓰지 않고 kmd 가 원문 그대로 옮긴다) → 새 이름을 이름 장부에 세우고 → 무엇을 왜 어디에 넣었는지 이력에 남긴다. 그 기록은 「넣음」.
  - **터미널**: 일 줄에서 그 파일을 누르면 Claude Code 가 하는 일(읽기 · 둘러보기 · 이름 맞추기 · 저장)이 줄마다 단계와 함께 보인다. 도는 동안 저절로 따라 내려간다. 끝나면 「문서에 넣었다. 회의록 · 이름 4」 와 [보기]. 파일은 가져오기 화면 어디에 끌어다 놓아도 된다 · 여러 파일은 「여러 파일」 일 하나로 묶이고 그 일을 그만두면 남은 파일은 보내지 않는다.
  - Claude Code 가 쓸 수 있는 것은 넣은 파일을 읽는 것과 그 지식의 kmd 도구뿐이다(쓰기 · 셸 · 웹 없음 · 다른 지식 없음). Claude 로그인이 없거나 「자동 정리에 Claude 쓰지 않음」 지식이면 규칙으로 넣는다(갈래 · 주제 문서): 까닭은 터미널 · 이력에. 한 번에 20 파일까지 Claude Code 로, 나머지는 규칙으로. 글로 바꾸기 · 기록 정리는 파일 셋씩 함께, 문서에 넣기는 하나씩. 일마다 쓰는 모델(Haiku · Sonnet · Opus)은 설정 › Claude 연결 › 「Claude 모델」.
  - **팀**: 팀 지식에 넣은 파일은 기록으로 남고, 팀의 정리 일꾼(정리 전용 로그인)이 같은 방식(Claude Code + kmd 도구)으로 넣는다 · 줄은 같은 터미널에. 글이 없는 pdf(스캔)는 개인 지식에 넣으면 개인 프로그램이 내 Claude 로 바꾼다. 한 번에 300 파일 · 200MB. (옛 폴더로 지식을 새로 세울 때는 파일마다 기록을 남기고 글 그대로 문서가 된다.)
- **가져올 곳(지켜보며 맞추기)**: 가져오는 곳이 줄로 선다(도는 모습 · 멈춤 · 그만두기는 일 줄에서 · 유형 · 이름 · 넣는 곳 · 언제 · 상태). 줄의 [지금 가져오기] · 머리의 [지금 모두 가져오기] · [+ 가져올 곳 더하기](팝업: 유형마다 칸이 다르다). **줄을 누르면 자세히**: 상태 · 마지막 바뀜을 보고, 주소 · 넣을 지식 › 문서 · 언제(매일이면 시각) · DB 접속 · 자격을 고치고 [고친 것 저장](주소 · 넣을 지식 · 문서가 바뀌면 처음부터 다시 가져온다 · 다른 지식으로 옮기면 옛 사본은 지우거나 내 문서로 남긴다), [전체 다시 맞추기], [지우기](들어온 문서는 그대로 둔다). 팀에서는 그 지식의 지식관리자 · 총괄 관리자가 한다(서버 폴더 · ssh 는 총괄 관리자만). 쓰기 자리는 [관리자에게 부탁].
  - **문서 폴더**: 바뀐 파일만 들어온다. 파일 넣기와 같은 길이다 — 파일마다 기록이 남고, 개인 프로그램은 Claude Code 가 · 팀은 정리가 갈래 · 주제 문서의 항목 자리를 골라 넣는다(파일 이름으로 문서를 세우지 않는다). pdf · hwp 도 kmd 가 글로 바꿔 들인다(글이 없는 pdf 만 Claude Code 가). 원본에서 지운 파일은 지식을 바꾸지 않는다. 예전에 사본으로 들어온 문서(원본이 주인)는 그대로 남는다.
  - **소스 코드(git)**: git 주소(개인 프로그램이면 저장소 폴더도). 더한 때의 묶음이 기준이고, 그 뒤 새로 올라온 묶음마다 기록이 하나 남는다. 제목은 묶음 설명, 첫 줄은 바뀐 값(3초 → 5초), 그리고 차이. 걸린 항목 글은 정리가 맞춘다.
  - **DB**: 호스트 · 포트 · DB · 스키마 · 계정. 테이블마다 정의 표를 채우고 바뀐 테이블만 고친다. 테이블마다 이름(`table:테이블` · 설명은 다른 이름)을 이름 장부에 세워 항목으로 보기에서 「테이블」 로 선다. 어떤 계정이든 읽기 전용으로 붙는다.

## 새 지식 · 보내기

- **지식 목록**: 맨 위 지식 폴더 띠(경로 · [경로 복사] · [동기화]) · 지식은 카드 그리드로 옆 메뉴에 보이는 순서대로(카드를 끌거나 ⋯ › 앞으로 · 뒤로). ⋯ › 「메뉴에서 빼기」 는 지우지 않고 옆 메뉴에서만 뺀다. 아래 「뺀 지식」 에서 [메뉴에 올리기]. 순서 · 뺌은 사람마다.
- **새 지식**: 그리드 끝 「+ 새 지식」 카드(또는 지식 고르기 › + 새 지식) → 팝업에 이름, 또는 폴더 경로(그 폴더의 md · docx · pptx · xlsx 를 한 번 들인다 · 원본은 그대로).
  - 개인 화면: 지식 폴더 안의 새 폴더로 선다. 받는 팀 지식을 함께 정할 수 있다(나중에 지식 보내기에서 정해도 된다). 지식 폴더 띠의 [바꾸기] 로 다른 폴더를 잇는다: 그 폴더에 `.kmd`(작업 환경)가 있으면 그대로 이어 쓰고, 없거나 빈 폴더면 새 지식 폴더로 세운다(다른 파일만 있는 폴더는 받지 않는다 · 옛 폴더는 그대로).
  - 팀 화면: 「+ 새 팀 지식」 은 총괄 관리자만. 세운 사람이 주인(지식관리자)이고 처음에는 다른 사람에게 보이지 않는다: 카드 ⋯ › 권한에서 자리를 준다.
- **나가기**: 머리 오른쪽의 내 이름 › 나가기(이 브라우저) · 모든 곳에서 나가기(다른 기기 · 브라우저도 · Claude Code 의 기기 열쇠는 그대로).
- **다른 곳에서 만든 지식 들이기**: 그 지식 폴더를 지식 폴더 안에 통째로 놓고 [동기화]. 새로 놓인 지식이 메뉴 맨 아래로 들어온다(git 이 없으면 세운다). 팀 서버의 지식 폴더는 총괄 관리자가 [동기화] 한다.
- **지식 보내기**(개인 화면에서만): 내 개인 지식의 **기록**과 **문서** 둘만 팀 지식으로 보낸다. 보내는 일은 개인 프로그램이 이 PC 의 기기 열쇠로 팀 서버에 한다(닿지 않으면 저절로 다시). 팀 화면에는 보내기 메뉴가 없다. 받는 지식으로 고를 수 있는 것은 내가 쓰기 자리 이상인 팀 지식뿐이다.
  - **보내는 길**: 맨 위에 보내는 지식(개인) → 받는 지식(팀). 받는 지식은 개인 지식마다 **하나로 묶여** 있어 보낼 때마다 고르지 않는다. 처음에는 받는 지식부터 정한다(정하기 전에는 보낼 것이 열리지 않는다). 보내는 지식을 고르는 줄마다 그 지식이 어디로 가는지 함께 보인다.
  - **받는 지식 바꾸기**: 새 팀 지식을 고르고 그 이름을 그대로 쳐야 바뀐다. 이미 보낸 것은 옛 지식에 그대로 남는다 · 바꾼 일은 이력에.
  - **탭**: 기록(먼저 · 보내지 않은 것 / 모두 · 제목으로 찾기) · 문서(늘 통째로 · 「보낸 적 없음」 · 「보낸 뒤 고침」 으로 보인다. 바뀐 곳은 받는 지식의 정리가 가른다) · 보낸 것.
  - 단추와 확인 창에 받는 지식 이름이 늘 들어간다([DPMS 지식으로 2개 보내기]). 누르면 고른 것마다 팀 지식에 기록 하나로 들어가고 그 지식의 정리 때 문서에 들어간다. 그새 받는 지식이 바뀌었으면 보내지 않는다.

- **개인 화면 › 설정**(개인 프로그램): 일반(지식 폴더 · 백업 자리 · 되살리기 · 저절로 하는 일 · 보내는 길) · Claude 연결(**내 Claude 로그인**: [Claude 로그인] 을 누르면 이 PC 에 「kmd: Claude 로그인」 창이 뜬다 · 일마다 모델) · 에이전트 설치(폴더 더하기 · 개인 지식 더하기 · 떼기 · 빼기 · 개인 지식만).

## 개인 프로그램 설치(팀 화면)

누구나 쓴다. 이 PC 에 개인 프로그램을 깔고 팀에 잇는 일 · 내 기기가 이 한 곳에 있다. 작업 폴더에 팀 지식을 붙이는 일은 팀 화면 › 설정 › 에이전트 설치. 개인 지식 · 개인 폴더의 내용은 여기에 나오지 않는다.

- **설치 · 업데이트 · 잇기 한 줄**: [한 줄 복사] → PowerShell 에 붙여 넣는다(10분 · 한 번). 개인 프로그램을 깔고 올리는 길은 이것 하나다.
  - 이 PC 에 개인 프로그램이 없으면 팀 서버의 판을 받아 깐다.
  - 깔려 있는데 팀 서버의 판보다 옛 판이면 그 판으로 올린다(새 판을 한 번 켜 보고 바꾼 뒤 다시 켠다 · 안 켜지면 앞 판 그대로 · 앞 판은 남는다). 같거나 더 새 판이면 올리지 않는다.
  - 끝에 팀에 잇는다(아래) · 개인 화면이 열린다. 복사한 칸에 이 한 줄이 가져오는 판 이름이 보인다.
- **팀에 잇기가 하는 일**: 이 PC 에 내 이름의 **기기 열쇠**를 만들어 Windows 자격 저장소에 두고, 이은 팀 주소를 개인 프로그램에 적는다. 이 열쇠로
  - Claude Code 가 팀 지식을 읽고 쓴다(연결 kmd-team · 작업 폴더에 붙인 팀 지식 · 아래 에이전트 설치).
  - 개인 화면의 지식 보내기가 팀 지식으로 보내고 · 받는 팀 지식 목록을 받아 온다.
  - 열쇠는 사람에 묶여 내 자리대로만 본다(받지 않은 지식은 이 열쇠로도 안 보인다). 잃어버린 PC 는 내 기기에서 끊는다. 팀 화면은 이 열쇠를 쓰지 않는다(아이디 · 비밀번호).
- **내 기기**: 팀에 이은 PC 목록(이름 · 이은 날 · 마지막으로 쓴 때)과 [끊기]. 팀 서버가 아는 것만 보인다(PC 에 묻지 않는다).

## 에이전트 설치(작업 폴더에 지식 붙이기)

팀 지식과 개인 지식은 따로 붙인다. 스킬 · 연결 · CLAUDE.md 안내가 둘로 나뉘고, 한 폴더에 둘 다 붙여도 서로 건드리지 않는다.

| | 팀 지식 | 개인 지식 |
|---|---|---|
| 붙이는 곳 | 팀 화면 › 설정 › 에이전트 설치(누구나) | 개인 화면 › 설정 › 에이전트 설치 · `kmd agent add '<개인 지식>'` |
| 필요한 것 | PowerShell 하나(개인 프로그램은 없어도 된다 · 지금은 Windows 만) | 개인 프로그램 |
| 스킬 | `kmd-team-work` · `kmd-team-save` | `kmd-work` · `kmd-save` · `kmd-build` |
| 연결(.mcp.json) | `kmd-team`(팀 서버) | `kmd`(이 PC) |
| CLAUDE.md 안내 | `kmd-team` 덩이 · 「이 폴더의 팀 지식」 표 | `kmd` 덩이 · 「이 폴더의 개인 지식」 표 |
| 남기면 보는 사람 | 그 팀 지식을 보는 팀 사람 | 나만 |

- **팀 지식 붙이기**: 붙일 팀 지식(내가 읽기 자리 이상인 것)의 [설치 명령 복사] → 작업 폴더의 PowerShell 에 붙여 넣고 Enter → 그 폴더에서 Claude Code 를 새로 연다. 한 줄(`irm '…/a/<표>?kn=…' | iex`)은 그 폴더에 팀 스킬 · 연결 · 안내만 쓴다. 개인 프로그램을 깔거나 올리지 않고, 늘 켜기 · 개인 화면 열기도 하지 않는다.
  - **팀 열쇠**: 연결은 이 PC 의 기기 열쇠로 팀 서버에 「누구인지」 알린다(내 자리대로만 읽고 쓴다). 열쇠는 Windows 자격 저장소에 둔다(DPAPI · 개인 프로그램과 같은 자리). 이미 있고 팀 서버가 받으면 그대로 쓴다. 없거나 끊겼을 때만 한 줄 안의 번호(10분 · 한 번)로 하나 받는다: 내 기기에 한 줄이 생긴다. 연결은 `%USERPROFILE%\.kmd\kmd-team-key.ps1` 이 열쇠(`%USERPROFILE%\.kmd\keys`)를 꺼내 쓴다(설정 파일에는 열쇠가 없다). `%APPDATA%` 에 두지 않는 것은 Claude 데스크톱 앱 안에서 그 자리가 앱 전용으로 가상화되기 때문이다.
  - 깨진 `.mcp.json` 은 고치지 않고 멈춘다. 다른 연결 · 사람이 쓴 CLAUDE.md 줄은 그대로다.
  - 예전 판이 붙인 폴더(팀 · 개인이 한 덩이): 팀 줄을 팀 덩이로 옮긴다. 그 덩이에 개인 지식이 없으면 옛 덩이와 옛 스킬을 걷는다. 개인 지식이 있으면 개인 화면 › 설정 › 에이전트 설치 › 지금 모두 최신으로.
- **개인 지식 붙이기**: 개인 화면 › 설정 › 에이전트 설치 › 폴더 더하기, 또는 `kmd agent add '<개인 지식>'`(다른 폴더는 `--dir`). 떼기 · 빼기도 거기서. 팀 연결 · 팀 덩이는 건드리지 않는다.
- **어디에 남기나**: 기본 지식은 없다. 세션이 남기기 전에 묻는다.
  - 팀 지식에 남길 때는 늘 「어느 팀 지식에 남길까요?」(표의 팀 지식이 하나면 그 이름으로 묻는다).
  - 개인 지식은 표의 지식이 여럿일 때 묻는다(하나면 그 지식에).
  - 한 폴더에 팀 · 개인이 다 붙어 있고 사람이 「남겨」 만 말하면 팀인지 개인인지부터 묻는다. 「팀 지식에 남겨」 · 「내 지식에 남겨」 처럼 말하면 바로 그쪽으로.
- 붙인 폴더의 이력은 두지 않는다. 한 폴더에 여러 지식을 붙이려면 차례로 붙인다(더하기 · 먼저 붙은 지식은 그대로).

## 기록과 이력

- **기록**: 그 자체로 지식이 될 글만: 사람 · 세션이 남긴 것, 넣은 파일, 받은 것, 소스 코드의 묶음 기록.
- **이력**(지식 관리 › 이력): 그 화면의 모든 지식(팀 화면은 내가 볼 수 있는 팀 지식 · 개인 화면은 개인 지식)에서 바뀐 것을 한 흐름으로(날마다): 내가 저장 · 가져오기 · 보내기 한 것, kmd 가 가져오고 정리한 것, 화면 · 편집기에서 바로 고친 것, 새 지식 · 지움 · 새 기기. 같은 일은 한 줄이다. 내 값이 바뀐 줄은 맨 위 「확인할 것」: [보기] 에서 비교 · 되돌리기. 갈래 · 지식으로 거르고, 줄을 누르면 펼쳐 그 일 · 문서를 연다. kmd 가 다룬 일은 지식의 git 에 남고(기록이 아니다), 나에게 온 줄은 7일 둔다.

## 멈춤 한 줄

저절로 하는 일(백업 · 가져오기 · 보내기 · 정리)이 멈추면 머리 띠 오른쪽에 「⚠ 경고 n」 단추가 선다. 누르면 팝업에 모두(무엇이 · 얼마나: 풀리는 길 · 그 일로 가는 단추). 화면 안에는 깔지 않는다. 잘 될 때는 단추가 없다. 팀 화면은 내가 볼 수 있는 팀 지식의 것만, 개인 화면은 개인 지식의 것만 보인다. 들어온 사람(이름 · 개인 프로그램/팀 서버)은 왼쪽 메뉴 맨 위: 누르면 설정 · (팀) 나가기.
