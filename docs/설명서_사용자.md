# kmd 설명서 — 쓰는 사람

kmd 는 팀과 내 PC 의 지식(문서 · 기록)을 한 곳에서 읽고, Claude Code 가 같은 지식으로 일하게 한다.

## 처음

1. 관리자에게 받은 **처음 들어오기 링크**를 연다 → 비밀번호를 정한다(브라우저가 제안하는 것을 쓰면 된다). 한 번 들어오면 일주일쯤 이어진다.
2. 비밀번호를 정한 그 화면의 **설치 한 줄 복사**(나중에는 설정 › 에이전트 설치) → PowerShell 에 붙여 넣는다. 10분 안에 한 번 쓴다.
   - 이 PC 에 kmd 가 없으면 팀 서버에서 PC 꾸러미를 받아 `%USERPROFILE%\.kmd-app` 에 깔고 사용자 PATH 에 `kmd` 를 더한다(관리자 권한 없이). 팀 서버에 꾸러미가 없으면 그렇다고 알린다 — 관리자에게 묻는다.
   - 묻는 것 없이 끝나고 ✓ 넷이 찍힌다.
   - ✓ 세웠다 — 이 PC 의 내 지식 자리(D:\kmd)와 백업 자리
   - ✓ 팀에 이었다 — 내 이름으로
   - ✓ Claude Code 에 이었다 — 새로 여는 것부터
   - ✓ 늘 켜기 — PC 를 켜면 저절로 켜고, 멈추면 다시 켠다. 끝에 **이 PC 의 kmd 화면**이 한 번 열린다.
3. 「새 기기가 이어졌다」 줄이 내 「이력」 에 남는다. 내가 한 것이 아니면 [보기] 에서 끊는다.

## 이 PC 의 kmd 화면 열기

이 PC 의 kmd(내 지식 · 파일 넣기 · 지켜보며 맞추기 · 보내기 · 설정)는 아이디 · 비밀번호가 없다 — 이 PC 의 kmd 가 여는 한 번용 주소로만 들어온다.

- **시작 메뉴 › kmd** 를 누른다. 꺼져 있으면 켜고 화면을 연다. 터미널이면 `kmd open`.
- 한 번 들어온 브라우저는 쓰는 동안 이어진다(마지막으로 쓴 날부터 30일).
- 주소창에 이 PC 주소(`127.0.0.1:7373`)만 치거나 지난 주소를 열면 「이 PC 의 kmd 화면을 연다」 안내가 선다 — 위처럼 다시 연다. 팀 kmd 의 아이디 · 비밀번호로는 들어오지 않는다.
- 팀 화면의 [내 PC 화면 열기] 도 이 브라우저가 이 PC 화면에 들어온 적이 있으면 바로, 아니면 같은 안내로 간다.

## Claude 로그인(이 PC)

설정 › **Claude 연결** — [Claude 로그인] 을 누르면 작업 표시줄에 **「kmd — Claude 로그인」 창**이 뜨고(`claude auth login`), 그 창이 브라우저를 연다. 브라우저에서 Claude 에 들어가면 끝 — 이 화면이 몇 초마다 저절로 확인해 「로그인됨」 으로 바뀐다([지금 확인] 도 있다). Claude Code 의 로그인은 진짜 터미널이 있어야 돌아서 이 화면 안에 넣지 못한다. [로그인 확인] 은 아주 작은 부르기 한 번으로 지금 로그인이 살아 있는지 본다(`claude auth status` 는 끝난 로그인도 「됨」 이라 말한다). 로그인이 끝났거나 한도에 닿으면 이 칸이 알려 주고, 그동안 기록은 규칙으로 문서에 들어간다.

## 화면

- **왼쪽 위 — 지식 고르기**: 지식을 고르고, 문서 · 항목 · 그래프 탭과 그 탭의 목록(나무)을 본다. 다른 화면에 가도 목록은 그대로 있다.
- **왼쪽 아래 — 지식 관리**(고른 지식에 따라): 모두 이력 · 가져오기 · 설정 / 개인 지식(내 PC · 팀 서버의 나만 쓰는 지식)은 + 지식 보내기 / 팀 지식은 + 정리 · 이 지식의 사람. 관리는 팀 서버 관리자에게 늘 보인다. 지식 고르기의 표지(팀 · 개인 · 내 PC)가 그 갈래다.
- 팀 화면에서 **내 PC 지식**을 고르면 읽기 · 고치기는 그 자리에서 되고, 그 지식의 이력 · 가져오기 · 지식 보내기는 내 PC 프로그램 화면에서 한다(팀 서버에는 한 조각도 가지 않는다 · 글 속 그림도 내 PC 에서 받는다). 내 PC 지식은 이 PC 를 이은 사람(설치 한 줄을 붙인 사람)이 팀에 들어왔을 때만 열린다 — 남이 내 브라우저로 팀에 들어오면 「이 PC 의 kmd 는 다른 사람의 것이다」. 이은 팀 화면은 내 PC 화면 › 설정 › 이어진 것에서 [끊기].
- **위 머리**: 가운데 빨리 열기 · 찾기, 오른쪽 설명서(새 탭 — 이 설명서) · 나.

## 보는 법 셋

- **문서** — 왼쪽 문서 탭의 나무에서 문서를 연다. 탭 · 나란히 보기(Ctrl \\) · 글 속 항목 이름에 마우스를 올리면 미리보기.
- **항목** — 테이블 · 화면 · API · 절차 · 용어처럼 이름 있는 것 하나하나. 「이 항목을 쓰는 곳」 이 같이 보인다.
- **그래프** — 항목 · 문서 · 기록이 어떻게 이어졌나. 점을 누르면 이웃만.

빨리 열기 **Ctrl O** · 찾기 **Ctrl K** · 명령 창 **Ctrl P**.

## 고치기

- 문서 위 [고치기] → 저장. 내 지식이면 바로 문서에 들어간다.
- 팀 지식이면 **기록**으로 남고, 그 지식의 정리 방식(정해진 시각 — 보통 02:30 · 실시간 · 손으로만)대로 kmd 가 문서에 넣는다. 그동안도 문서 옆에 같이 읽힌다.
- 팀 서버의 **개인 지식**(나만 쓰는 지식)은 기록이 남는 즉시 문서에 — 내 PC 프로그램이 켜져 있으면 **내 Claude** 로 다듬어 넣는다(팀의 Claude 로는 나가지 않는다). 내 PC 프로그램이 없거나 오래 꺼져 있으면 규칙으로 넣는다.
- 「나만」 은 — 화면 · 찾기 · Claude Code(MCP)에서 나만 본다. 팀원도 관리자도 보지 못하고, 관리 화면에는 「남의 개인 지식 n」 처럼 수로만 선다. 다만 팀 서버를 돌보는 사람은 서버의 디스크 · 백업으로 볼 수 있고, 팀 서버가 GitLab 으로 백업하면 그 백업 그룹을 읽는 사람도 볼 수 있다. 개인 · 주인은 관리자가 바꾼다(이 지식의 사람 › 주인 · 갈래 · 서버에서 `kmd owner`) — 지식 안의 `_members.md` 에도 적혀 백업 · 되살림을 따라간다. 떠나면 관리자가 넘겨받는다.
- **이 PC** 는 정리가 따로 없다 — 기록(세션이 남긴 것 · 화면에서 남긴 것 · 받은 것 · 소스 코드의 묶음 기록 · 넣은 파일)은 남는 즉시 kmd 가 문서에 넣는다. Claude 로 다듬어 넣고(검사를 넘을 때만), Claude 로그인이 없거나 검사를 못 넘으면 규칙으로 — 항목이 정해진 기록은 그 항목 끝에 글을 붙이고, 이름 없는 기록은 새 문서로. 켤 때 쌓여 있던 기록도 넣는다. 넣은 일은 이력에.
- 값이 바뀌면(예: 10% → 20%) 내 「이력」 맨 위 「확인할 것」 에 노란 줄로 알린다. 줄마다 되돌릴 수 있다.
- 편집기로 md 파일을 직접 고쳐도 된다(이 PC) — 30초 조용하면 저절로 들어간다. kmd 가 꺼져 있던 동안 고친 것은 켤 때 거둔다. 기록(`work/`) · 이름 장부는 고치지 않는다 — 고치면 kmd 가 되돌리고, 고친 글은 사본으로 남겨 「이력」 노란 줄로 사본 자리를 알린다.
- 고치는 창 — [항목 더하기] · 항목을 지우려면 그 「## 」 줄과 글을 지운다 · 이름만 바꾸려면 「## 」 줄만 고친다(지우기 · 이름 바꾸기는 저장 전에 한 번 묻는다). **Ctrl S** 저장 · **Esc** 그만두기.
- 쓰던 글은 찾기를 열고 닫거나 다른 화면에 갔다 와도 그대로다. 창을 닫거나 새로 고치면 묻는다 · 저장하지 않고 닫았으면 다음 [고치기] 때 되살린다(이 탭 안에서). 들어온 것이 끝났으면(12시간 쉬었거나 7일) 저장할 때 그 자리에서 비밀번호를 묻고 이어서 저장한다.

## 가져오기(옛 자료 · 파일 · 폴더)

탭 셋 — **일 줄** · **가져올 곳** · **끝난 일**.

- **일 줄** — 들여오는 일은 모두 여기에 선다: 넣은 파일 · 여러 파일 묶음 · 가져오기(문서 폴더 · git · DB) · 기록을 문서에 넣기 · (팀) 정리 일감. 도는 중 · 멈춤/확인할 것/못함 · 기다림(차례 번호)으로 나뉜다.
  - **네 단계** — 일은 늘 수집 › 검토 › 기록 생성 › 문서 생성. 줄의 작은 네 칸 막대가 지금 단계다. 줄을 누르면 오른쪽 자세히에 흐름 그림(단계마다 안의 걸음 · 걸린 시간) · 터미널 · 만든 것(문서 · 기록 · 이름). 흐름의 단계를 누르면 터미널에 그 단계의 줄만.
  - **손잡이** — [멈춤] 은 지금 단계를 마치고 선다 · [이어서] · [그만두기] 는 바로 끊는다(도는 Claude Code 를 끈다 — 끝난 단계에서 남긴 기록은 그대로 · 정리 때 문서에 넣는다) · [다시] 는 못한 단계부터 · 기다리는 일은 [맨 앞으로] 와 끌어서 순서 바꾸기 · [빼기]. 넣은 사람 · 정리하는 사람 · 관리자가 한다(내 PC 는 누구나).
  - **확인할 것** — 가져오기가 한꺼번에 크게 바뀌어(사라짐이 많다) 쓰지 않고 멈췄다. [그대로 맞추기] 는 브레이크를 넘어 원본대로 쓴다(이력에서 되돌릴 수 있다) · [이번은 건너뛰기] 는 다음 정한 때에 다시 본다.
  - **줄 멈춤** — 도는 일은 다음 단계 앞에서 서고 기다리는 일은 시작하지 않는다(정한 때 · 실시간으로 오는 일도 줄에만 선다). [줄 다시 돌리기] 로 잇는다. **동시에 도는 수** — Claude(문서 생성) 기본 1 · 가져오기 기본 2 · 일 줄 머리에서 1~4. 팀에서는 둘 다 관리자가.
  - 다시 켜도 일 줄은 남는다 — 꺼질 때 돌던 파일은 그 단계부터 다시, 멈춘 일은 멈춘 채로.
- **끝난 일** — 30일 동안 남는다(터미널 줄까지). 파일 · 제목으로 찾고 갈래 · 결과(끝남 · 그만둠 · 못함)로 거른다. 그만둔 일은 [다시].
- **파일 · 폴더 넣기** — 끌어다 놓으면 파일마다 **기록**이 된다(md · docx · pptx · xlsx · hwpx · hwp · pdf 는 kmd 가 글로 바꾸고 — 목차 · 쪽 번호 · 되풀이 머리글 · 빈 열은 뺀다 —, 글이 없는 pdf(스캔) · 암호 · 배포용 파일만 Claude Code 가 원본을 읽어 글로 바꾼다 · 원본은 첨부로).
  - **세션처럼 들인다** — 파일마다 kmd 가 Claude Code 를 띄워 세션에서 일하듯 넣는다: 파일을 끝까지 읽고 → 지식을 둘러보고 → 글 속 이름(테이블 · 화면 · 절차 · 용어 …)을 맞추고 → 갈래 · 주제 문서의 항목으로 넣고(문서 이름은 파일 이름이 아니다 — 회의 · 통화 파일은 회의록 › 「2026-10-21 HNC 통화 — …」 · 파일 글은 Claude 가 다시 쓰지 않고 kmd 가 원문 그대로 옮긴다) → 새 이름을 이름 장부에 세우고 → 무엇을 왜 어디에 넣었는지 이력에 남긴다. 그 기록은 「넣음」.
  - **터미널** — 일 줄에서 그 파일을 누르면 Claude Code 가 하는 일(읽기 · 둘러보기 · 이름 맞추기 · 저장)이 줄마다 단계와 함께 보인다. 도는 동안 저절로 따라 내려간다. 끝나면 「문서에 넣었다 — 회의록 · 이름 4」 와 [보기]. 파일은 가져오기 화면 어디에 끌어다 놓아도 된다 · 여러 파일은 「여러 파일」 일 하나로 묶이고 그 일을 그만두면 남은 파일은 보내지 않는다.
  - Claude Code 가 쓸 수 있는 것은 넣은 파일을 읽는 것과 그 지식의 kmd 도구뿐이다(쓰기 · 셸 · 웹 없음 · 다른 지식 없음). Claude 로그인이 없거나 「자동 정리에 Claude 쓰지 않음」 지식이면 규칙으로 넣는다(갈래 · 주제 문서) — 까닭은 터미널 · 이력에. 한 번에 20 파일까지 Claude Code 로, 나머지는 규칙으로. 글로 바꾸기 · 기록 정리는 파일 셋씩 함께, 문서에 넣기는 하나씩. 일마다 쓰는 모델(Haiku · Sonnet · Opus)은 설정 › Claude 연결 › 「Claude 모델」.
  - **팀** — 넣은 파일은 기록으로 남고, 팀의 정리 일꾼(정리 전용 로그인)이 같은 방식(Claude Code + kmd 도구)으로 넣는다 · 줄은 같은 터미널에. 글이 없는 pdf(스캔)는 내 PC 프로그램에서 넣는다. 한 번에 300 파일 · 200MB. (옛 폴더로 지식을 새로 세울 때는 파일마다 기록을 남기고 글 그대로 문서가 된다.)
- **가져올 곳(지켜보며 맞추기)** — 가져오는 곳이 줄로 선다(도는 모습 · 멈춤 · 그만두기는 일 줄에서 · 유형 · 이름 · 넣는 곳 · 언제 · 상태). 줄의 [지금 가져오기] · 머리의 [지금 모두 가져오기] · [+ 가져올 곳 더하기](팝업 — 유형마다 칸이 다르다). **줄을 누르면 자세히** — 상태 · 마지막 바뀜을 보고, 주소 · 넣을 문서 · 언제(매일이면 시각) · DB 접속 · 자격을 고치고 [고친 것 저장](주소 · 넣을 문서가 바뀌면 처음부터 다시 가져온다), [전체 다시 맞추기], [지우기](들어온 문서는 그대로 둔다). 팀에서는 관리자가 한다 — [더해 달라고 부탁].
  - **문서 폴더** — 바뀐 파일만 들어온다 — 파일마다 기록이 먼저 남고 그 기록이 문서가 된다(원본이 주인 · 문서의 「이 문서가 온 곳」 에 그 기록). pdf · hwp 도 kmd 가 글로 바꿔 문서로(글이 없는 pdf 만 Claude Code 가 · 같은 파일은 다시 바꾸지 않는다).
  - **소스 코드(git)** — git 주소(이 PC 면 저장소 폴더도). 더한 때의 묶음이 기준이고, 그 뒤 새로 올라온 묶음마다 기록이 하나 남는다 — 제목은 묶음 설명, 첫 줄은 바뀐 값(3초 → 5초), 그리고 차이. 걸린 항목 글은 정리가 맞춘다.
  - **DB** — 호스트 · 포트 · DB · 스키마 · 계정. 테이블마다 정의 표를 채우고 바뀐 테이블만 고친다. 테이블마다 이름(`table:테이블` · 설명은 다른 이름)을 이름 장부에 세워 항목으로 보기에서 「테이블」 로 선다. 어떤 계정이든 읽기 전용으로 붙는다.

## 새 지식 · 보내기

- **지식 목록** — 맨 위 지식 폴더 띠(경로 · [경로 복사] · [동기화]) · 지식은 카드 그리드로 옆 메뉴에 보이는 순서대로(카드를 끌거나 ⋯ › 앞으로 · 뒤로). ⋯ › 「메뉴에서 빼기」 는 지우지 않고 옆 메뉴에서만 뺀다 — 아래 「뺀 지식」 에서 [메뉴에 올리기]. 순서 · 뺌은 사람마다.
- **새 지식** — 그리드 끝 「+ 새 지식」 카드(또는 지식 고르기 › + 새 지식) → 팝업에 이름, 또는 **내 PC 폴더 경로**(그 폴더의 md · docx · pptx · xlsx 를 한 번 들인다 · 원본은 그대로). 이 PC 는 지식 폴더 안의 새 폴더로 선다.
  - 팀 화면에서는 **내 PC** 로 만든다 — 내 PC 프로그램의 지식 폴더에 서고, 팀 화면에도 「내 PC」 로 열린다(팀 서버에는 가지 않는다). 내 PC 프로그램이 켜져 있어야 한다.
  - 팀 서버에 지식을 세우는 것(팀 지식 · 팀 서버 안 내 지식)은 관리자만 한다. 새 지식은 메뉴 맨 아래로.
- **나가기** — 머리 오른쪽의 내 이름 › 나가기(이 브라우저) · 모든 곳에서 나가기(다른 기기 · 브라우저도 · Claude Code 의 기기 열쇠는 그대로).
- **다른 곳에서 만든 지식 들이기** — 그 지식 폴더를 지식 폴더 안에 통째로 놓고 [동기화]. 새로 놓인 지식이 메뉴 맨 아래로 들어온다(git 이 없으면 세운다). 팀 서버의 지식 폴더는 관리자가 [동기화] 한다.
- **보내기** — 만들어진 지식(문서 · 기록)만 보낸다. 내 지식에 보낼 곳(팀 지식)을 정해 두면 화면이 둘로 선다.
  - **바뀐 것** — 보낸 뒤 바뀐 문서(새 문서면 전체 · 아니면 바뀐 항목만)와 새로 남은 기록(전체)이 저절로 모여 골라져 있다. [전체 체크] · [전체 해제] · 줄마다 체크. 고르지 않은 것은 다음에 그대로 남는다.
  - **지식** — 그 지식의 문서 목록 · 기록 목록에서 여럿 골라 전체로 보낸다(이름으로 거르기).
  - 영역마다 보내기 단추가 있다([바뀐 것 N개 보내기] · [고른 N개 보내기]). 누르면 고른 것마다 팀 지식에 기록 하나로 들어가고 그 지식의 정리 때 문서에 들어간다. 팀 서버에 닿지 않으면 닿을 때 저절로 보낸다.

## 기록과 이력

- **기록** — 그 자체로 지식이 될 글만: 사람 · 세션이 남긴 것, 넣은 파일, 받은 것, 소스 코드의 묶음 기록.
- **이력**(지식 관리 › 이력) — 모든 지식에서 바뀐 것을 한 흐름으로(날마다): 내가 저장 · 가져오기 · 보내기 한 것, kmd 가 가져오고 정리한 것, 화면 · 편집기에서 바로 고친 것, 새 지식 · 지움 · 새 기기. 같은 일은 한 줄이다. 내 값이 바뀐 줄은 맨 위 「확인할 것」 — [보기] 에서 비교 · 되돌리기. 갈래 · 지식으로 거르고, 줄을 누르면 펼쳐 그 일 · 문서를 연다. kmd 가 다룬 일은 지식의 git 에 남고(기록이 아니다), 나에게 온 줄은 7일 둔다.

## 멈춤 한 줄

저절로 하는 일(백업 · 가져오기 · 보내기 · 정리)이 멈추면 머리 띠 오른쪽에 「⚠ 경고 n」 단추가 선다 — 누르면 팝업에 모두(무엇이 · 얼마나 — 풀리는 길 · 그 일로 가는 단추). 화면 안에는 깔지 않는다. 잘 될 때는 단추가 없다. 들어온 사람(이름 · 이 PC/팀 서버)은 왼쪽 메뉴 맨 위 — 누르면 설정 · (팀) 나가기.
