# kmd 디자인 컨벤션 v0.2

화면을 고치거나 더할 때 이 문서를 먼저 본다. 기준 CSS 는 `app/kmd.css` — 맨 위 `:root` 가 **디자인 토큰의 유일한 자리**다. 부품을 한눈에 보는 견본은 `<서버 주소>/styleguide.html`(`app/styleguide.html`). **새 화면 · 새 부품은 여기 있는 것만으로 짓는다** — 없는 것이 필요하면 이 문서에 먼저 더하고 CSS 에 부품으로 만든 뒤 쓴다(화면 코드 안 `style="…"` 로 새 모양을 만들지 않는다 — 자리 맞춤 margin · width 정도만, 그것도 토큰 `var(--sp-*)` 로).

v0.2 에서 바뀐 것: 토큰을 색 밖(글 · 간격 · 모서리 · 그림자 · 층 · 폭)으로 넓혔다 · 부품마다 상태(기본 · hover · 비활성 · 선택 · 초점)를 정했다 · 반응형 끊는 점을 600 · 1024 둘로 정했다(11절).

## 1. 바탕(토큰)

CSS 에 색 · 크기를 바로 쓰지 않는다. 아래 토큰만 쓴다(`var(--…)`). 예외: `0` · `1px` 선 · `50%` · `100%`.

## 2. 화면 짜임

```
.pg-h   화면 머리 — 제목(.big) · 한 줄 설명(.lead) · 오른쪽 화면 단추(있으면 최대 둘)
.sec-h  영역 머리 — 영역 제목 · 작은 설명 · 오른쪽 영역 단추
.card   카드 — .ch(머리: 제목 · small 설명 · .r 단추) · .cb(몸) · .cf(발: 흐린 도움말 · 단추)
```

- 화면 하나는 「화면 머리 → 영역(영역 머리 + 카드) …」 순서다. 영역이 하나면 영역 머리를 생략한다.
- 카드 몸에 `overflow` 를 두지 않는다(팝업이 잘린다). 넓은 표는 `.tblwrap` 로 감싸고 그 안에는 팝업을 두지 않는다.
- 최대 폭 — 글 화면 820px · 목록 · 설정 화면 980px · 그리드 화면 1100px.

## 3. 단추와 링크(C-단추)

| 부품 | 쓰는 곳 |
|---|---|
| `.btn.pri` | 그 영역의 주된 일 하나(더하기 · 저장 · 보내기 · 지금 모두 가져오기). 영역마다 하나까지 |
| `.btn` | 그 밖의 일(연결 확인 · 지금 가져오기 · 동기화 · 경로 복사) |
| `.btn.ghost` | 줄 안의 작은 일 · 닫기 · 취소(테두리 없음) |
| `.btn.danger` | 되돌릴 수 없는 일(지우기) — 확인 팝업 안에서만 |
| `.btn.sm` | 줄 · 카드 안(높이 24px) |
| `.kebab`(⋯) | 드물게 쓰는 일 묶음 — 펼치면 `.pop` 메뉴 |
| 링크(`a` · `.lk`) | **옮겨 가기만**(다른 화면 · 문서 열기 · 「보기」). 무엇을 바꾸거나 돌리는 일은 링크로 만들지 않는다 |

- 단추 글은 동사로 끝낸다(「더하기」 · 「지금 가져오기」 · 「메뉴에 올리기」). 수가 있으면 단추 안에(「고른 3개 보내기」).
- 도는 중이면 그 단추를 `disabled` + 글을 「가져오는 중…」 으로.

## 4. 팝업 · 모달(C-팝업)

- **팝업 메뉴**(`.pop`) — 화면 맨 위 층(`position:fixed`)에 띄우고 자리는 누른 단추에서 잰다. 카드 · 표 · 스크롤 상자에 잘리지 않는다. 바깥을 누르거나 Esc 면 닫힌다. 화면 코드는 `popHtml(key, items)` 하나로 그린다.
- **모달**(`.scrim > .modal`) — 칸을 받거나 · 하나를 자세히 보고 고치거나 · 위험한 일을 확인할 때. 짜임은 `.mh`(제목 · 닫기 ×) · `.mb`(몸) · `.mf`(왼쪽 흐린 말 · 오른쪽 단추 — 취소(ghost) · 주 단추). 폭은 420 · 560 · 760px 셋. Esc · 바깥 누름 · × 로 닫는다(도는 중이면 닫지 않는다).
- 지우기 확인은 모달 안 `.btn.danger` · 지식 지우기처럼 큰 일은 이름을 다시 치게 한다.

## 5. 목록 · 그리드 · 칩

- **줄**(`.srow`) — 왼쪽 표지(유형 · 아이콘) · 이름(굵게) + 작은 둘째 줄 · 가운데 정보 칸 · 오른쪽 칩 · 작은 단추. 줄 전체를 누르면 자세히(모달)로. 줄 안 단추는 누름이 줄로 번지지 않게.
- **그리드 카드**(`.kgrid > .kcard`) — 지식처럼 「고르는 것」. 이름 · 표지 · 두 줄 정보 · 오른쪽 위 ⋯ · 끌어 순서 바꾸기. 더하기는 그리드 끝 점선 카드(`.kcard.add`).
- **칩**(`.chip`) — 상태만: `c-acc`(됨 · 바뀜) · `c-mute`(그대로 · 쉼) · `c-warn`(멈춤 · 값 바뀜) · `c-danger`(못 함) · `c-pend`(도는 중 · 기다림). 칩을 단추로 쓰지 않는다.
- **표지**(`.kt`) — 갈래(팀 · 개인 · 유형)만.
- **고르는 줄**(`.drow`) — 체크 · 아이콘 · 이름 + 둘째 줄 · 칩 · 오른쪽 작은 고르기(`.seg.in`). 줄 전체가 체크다. 고를 수 없는 줄은 `.dim`.
- **하나 고르기 줄**(`.trow`) — 라디오 · 이름 + 둘째 줄 · 표지. 하나만 고르는 목록(받는 지식 정하기 등).
- **현황판**(`.td-board > .td-ps`) — 절차의 단계마다 같은 꼴 한 칸: 번호 · 단계 이름 · 큰 수 + 단위 · 칩 한 줄. 단계 설명은 칸에 올리면 뜨는 `.tip`(칸 안에 길게 쓰지 않는다). 도는 단계 `.run` · 끝난 단계 `.done`.
- **트리 그리드**(`.td-grid > .td-r` · 묶음 줄 `.td-g`) — 머리 줄 하나(`.td-r.hd`)에 칸 이름 · 묶음(사람 · 자리 · 결과) 아래 줄은 들여 쓰고 왼쪽에 잇는 줄(`.it` · 마지막 `.last`). 칸이 많아 좁아지면(컨테이너 760px · 칸 적은 `.h` 는 480px) 두 줄로 접는다. 고른 것이 있으면 아래에 붙는 띠 `.td-selbar`.
- **어디서 어디로**(`.route` · 확인 창은 `.bigroute`) — 왼쪽 보내는 것 → 오른쪽 받는 것 · 화살표 하나. 무엇이 어디로 가는지가 틀리면 큰일인 화면은 맨 위에 두고 단추 · 확인 창에 받는 곳 이름을 넣는다(지식 보내기).

## 6. 칸

- `.field > label + .inp + .hint` 하나가 칸 하나. 둘씩 놓을 때는 `.fgrid`(2칸 그리드 · 좁으면 1칸).
- 칸 아래 도움말은 `.hint` 한 줄. 오류는 모달 · 카드 안 `.callout.danger` 한 줄(어느 칸인지 말한다).
- 비밀(비밀번호 · 토큰)은 `type=password` · `autocomplete=new-password` · 고칠 때는 빈 칸 = 「그대로」.

## 7. 터미널(C-터미널)

- `.term` — 어두운 바탕(#0f141c) · 모노 12px · 줄 높이 1.55 · 최대 높이 320px · 새 줄이 오면 아래로(사람이 위로 올려 보고 있으면 따라가지 않는다).
- 줄 갈래 — `say`(Claude 의 말 · 흰 글) · `tool`(`▸ 도구 요약` · 파랑) · `ok`(`✓` · 초록) · `err`(`✗` · 빨강) · `sys`(kmd 의 알림 · 흐림) · `cost`(끝 · 흐림).
- 머리 줄(`.term-h`) — 무엇을 하는가 · 상태 칩 · 걸린 시간 · 접기.

## 8. 빈 상태 · 도는 중 · 알림

- 빈 상태(`.empty2`) — 굵은 한 줄 + 다음에 할 일 단추(또는 링크로 옮겨 가기).
- 화면 위 알림은 `.callout`(멈춤 줄 `.stop`). 잠깐 알림은 `toast`(4초).
- 도는 중 — 그 줄의 칩 `c-pend 「… 중」` · 단추 disabled. 전체를 가리는 「불러오는 중」 은 화면을 처음 열 때만.

## 9. 말

- 기존 규칙 그대로 — 쉬운 말 · 금지어(좌표 · 섹션 · 원천 · 기준선 · 큐레이션 · 대기열 · 판정 · 토큰 · 커밋 · 레포 · 미러 · 동기화 · LLM · RAG · 노드 · 엣지 · 백링크 …)는 화면 · 세션 응답 · 오류 글에 쓰지 않는다. 단, 운영자가 직접 정한 단추 이름 「동기화」(지식 폴더 다시 읽기)는 예외로 쓴다(요구 v0.2 R2.5).
- 단추 · 메뉴 글에 ① ② 같은 글자를 쓰지 않는다.
- 용어집(같은 것은 같은 이름으로):

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 개인 프로그램(그 PC 에 깐 kmd) · 개인 화면 | 이 PC 의 kmd · 내 PC 쪽 · 내 PC 의 kmd · PC 쪽 · 내 PC(지식 꼬리표) |
| 팀 프로그램(팀 서버) · 팀 화면 | 서버 쪽 |
| 반영 대기 n | 아직 문서에 안 넣은 기록 n(화면 칩) |
| 출처 | 경과 |
| 읽기 · 쓰기 · 관리(지식 자리) | 기록(자리 이름으로) · 정리(자리 이름으로) |
| 취소(창 닫기) · 잠깐 멈춤(이어 할 수 있음) · 그만두기(도는 일을 끝냄) | 멈추기(이어 할 수 있는지 모름) · 그만 |

## 10. 부품 상태

모든 누르는 것은 `<button>` 또는 `href` 있는 `<a>` 다(키보드로 닿게). div · span 에 `data-a` 만 달지 않는다 — 어쩔 수 없으면 `role="button" tabindex="0"`(위임 처리기가 Enter · Space 를 누름으로 바꾼다).

| 부품 | 기본 | hover | 비활성 | 선택 | 초점(키보드) |
|---|---|---|---|---|---|
| `.btn.pri` 주 단추 | accent 바탕 · on-accent 글 | `--accent-hover` | 바탕 유지 · opacity .5 · `cursor:not-allowed` · hover 없음 | — | `--focus-ring` |
| `.btn` 보조 | surface · border-strong 선 | `--hover` 바탕 | 위와 같음 | `.on`: accent-bg · accent 글 | 같음 |
| `.btn.danger` 위험 | danger 글 · danger-line 선 | danger-bg 바탕 | 위와 같음 | — | 같음 |
| `.btn.ghost` · `.lk` 글 단추 | 선 없음 · text-2 (`.lk` 는 accent) | `--hover` 바탕 / 밑줄 | text-3 | — | 같음 |
| `.inp` 칸 | surface · border-strong | border-strong 진하게 | surface-2 바탕 · text-3 | — | accent 선 + focus-ring |
| `.chip` 칩(상태만) | 갈래 색 바탕 · 선 | 없음(누르지 않는다) | — | — | — |
| `.card` | surface · border · shadow-1 | 누르는 카드(`.kcard`)만 border-strong | `.dim` opacity .55 | `.on` accent-line 선 | focus-ring |
| `.tabs` 탭 | text-2 | text · hover 바탕 | text-3 | `.on`: accent 밑줄 · text | focus-ring · `role=tab` |
| 모달 | `.scrim.fix > .modal` · `role=dialog` · `aria-modal` | — | 도는 중이면 닫기 막음 | — | 열면 첫 칸에 초점 · Tab 은 창 안에서만 |
| 표 `table.t` | 머리 surface-2 | 줄 `--hover` | — | `.sel` accent-bg | — |
| 빈 화면 `.empty2` | 굵은 한 줄 + 다음에 할 일 단추 | | | | |
| 읽는 중 `.loading` | 빙빙이 + 「읽는 중…」 | | | | |
| 오류 `.callout.danger` + 「다시 읽기」 단추 | 무엇이 · 왜 · 어떻게 다시 | | | | |

- 「취소」 = 창 · 편집을 닫는다(아무것도 바꾸지 않음). 「잠깐 멈춤」 = 도는 일을 세운다(칩 「멈춤」 · [이어서] 로 잇는다). 「그만두기」 = 도는 일을 끝낸다(칩 「그만둠」 · 이어 할 수 없다). 셋 다 창의 오른쪽 아래, 주 단추 왼쪽에 `.btn.ghost` 로 둔다.
- 브라우저 `confirm()` · `prompt()` 를 쓰지 않는다 — `askHtml`(공통 확인 창: 제목 · 설명 · 위험 단추 이름 · 취소).

## 11. 반응형

| 폭 | 이름 | 짜임 |
|---|---|---|
| 1025px 이상 | 데스크톱 | 옆 메뉴(248) + 본문 + 오른쪽 칸(300) |
| 601 ~ 1024px | 태블릿 | 옆 메뉴(248) + 본문. **오른쪽 칸은 접힌다** — 머리 줄 「옆 칸」 단추로 오른쪽에서 밀려 나오는 서랍(덮개)로 연다 |
| 600px 이하 | 모바일 | 본문만. **옆 메뉴는 서랍** — 머리 줄 맨 왼쪽 ☰ 로 연다. 머리 줄은 ☰ · 지식 이름 · 찾기 아이콘 · 지금 하는 일 점 |

| 부품 | 좁아질 때 |
|---|---|
| 표 | `.tblwrap` 로 감싸 가로로 밀어 본다(표만 밀리고 화면은 안 밀린다). 문서 본문 표도 서버가 감싼다 |
| 탭 줄 | 줄바꿈하지 않고 가로로 밀어 본다(`overflow-x:auto`) |
| 모달 | 폭 `min(N, 100% - 24px)` · 600 이하에서 아래에 붙는 시트(폭 100% · 높이 최대 `90dvh` · 몸이 스크롤) · 단추 줄은 줄바꿈 |
| 찾기 창 · 확인 창 | 화면에 고정(`position:fixed`) — 스크롤해도 화면 안에 뜬다 |
| 그리드(`.kgrid` · `.tiles` · `.fgrid` · `.g2`) | 600 이하 1칸 |
| 화면 머리 `.pg-h` · 영역 머리 | 단추가 아래 줄로 내려간다 |
| 긴 이름 · 경로 | `overflow-wrap:anywhere` · 말줄임이면 `title` 로 전체 |
| 그래프 | 높이 `min(420px, 60dvh)` |

- 높이는 `100dvh`(모바일 주소창)를 쓴다.
- 고정 px 폭은 토큰(`--w-*`)과 `min()` 으로만: `width:min(560px, 100%)`.
