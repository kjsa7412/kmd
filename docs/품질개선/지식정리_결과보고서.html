한 일 순서

  1. 도는 일이 없는 것을 보고 지식 셋과 .kmd 를 /srv/kmd-snap-20261102(700, kmd)에 남겼다.
  2. 줄표 꼴 · 지울 목록 · 사람 지우는 법을 사람에게 확인받았다(쌍점 · 마침표 / 목록대로 / 장부에서 완전히).
  3. GitLab 최신을 받은 로컬 클론에서 고쳤다. 참고 블록 · 표지는 sections.js(splitRef · withRef · logLine), 장부는 namebook.js, 정리는 core/save.js save(system)로 썼다.
  4. 기록 172건은 하위 작업자 6, 문서 본문은 2 가 나눠 고쳤고, 값(수 · 코드 · 「」 · 따옴표 값)이 빠지지 않았는지 git HEAD 와 견줘 검사했다.
  5. 줄표는 한 함수로 바꿨다. 머리가 바뀐 곳은 참고 블록 이름 · 자리 장부 행을 같은 함수로 맞췄고, 기록 머리말은 yaml 로 다시 읽어 견줬다. 마침표로 바뀐 곳의 앞 낱말을 모두 보고 「개요 · 필요」 를 문장 끝으로 본 잘못을 고쳐 다시 돌렸다.
  6. GitLab 에 올리고, 서버에서 kmd · kmd-worker 를 멈춘 뒤 fast-forward 로 받았다. 테스트 데이터를 지우고 새 kmd 를 깔아 다시 켰다.
