## 정한 것(권장안으로 진행 — 사용자가 중간 검토 없이 진행하라고 함)

| # | 정한 것 | 까닭 |
|---|---|---|
| D1 | 토큰은 `app/kmd.css` 의 `:root` 한 곳 · 서버 페이지(`/manual` · `/ok` · `/dl`)도 같은 토큰 | 따로 파일을 두면 화면이 두 곳을 읽는다 |
| D2 | 끊는 점 600 · 1024 둘 · 오른쪽 칸은 1024 이하 서랍 · 옆 메뉴는 600 이하 서랍 | 1024 에서 3단이면 본문이 390px 로 모바일보다 좁았다 |
| D3 | 시스템 참고 정보는 문서 끝 `<!-- kmd:참고 -->` 블록 하나 + 눈에 안 보이는 표지 셋(applied · watched · baseline) | frontmatter 로 옮기면 applied 를 쫓는 되돌리기(git log -S)와 기존 표지를 모두 바꿔야 한다. 표지는 이미 「정해진 문법」 이다 |
| D4 | 「경과」 → 참고 블록으로 옮긴다(옛 꼴은 읽을 때 받아 주고 쓸 때 새 꼴로) · 옮기기 명령 `kmd docfmt` | 본문 끝에 기록 링크가 섞이는 것이 가장 큰 혼선이었다 |
| D5 | 저장 검사 `E_FORMAT`: 사람 · 세션 글의 기록 링크 · 시스템 주소 · 표지 밖 주석 · 경과 꼬리 · 머리 줄 | kmd 자신의 쓰기는 고쳐서 넣는다 |
| D6 | 「지금 하는 일」 → 가져오기 › 일 줄(그 일 고름 · 스크롤 · 빛냄) / 팀 정리 → 정리 › 정리 일 줄. 문서는 줄 끝 작은 「문서」 | 진행 현황이 있는 곳으로 |
| D7 | 권한은 `owners.json` 의 `access` + `groups` · 옛 지식은 `all=write`(지금과 같음) · 주인 · 정리하는 사람은 관리 | 잠금 · 셸 공유가 이미 있는 장부 |
| D8 | 권한 없는 지식은 모든 화면 · API · MCP 에서 「없는 지식」(404) | 있다는 것도 드러내지 않는다 |
