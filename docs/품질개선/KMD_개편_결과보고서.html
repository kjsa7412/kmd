원인 · 고친 것 · 남은 것

원인

  • 기록은 먼저 쌓이고 문서 반영은 「정리」 가 모아서 나중에 했다. 반영 대기가 쌓이고, 정리 일꾼 호출이 느리고 비싸며, 검사를 못 넘은 조각이 끝없이 다시 돌았다.
  • 채널(세션 · 고치기 · 파일 넣기 · 가져올 곳 · 보내기)마다 저장 길이 달라 권한 · 검사 · 기록 모양이 갈렸다.

고친 것

  • 저장 문 하나: 기록 + 조각(edits · base 지문)을 hub.save 한 덩이로, 팀은 줄 안에서 조각마다 검사(core/gate.js) · 못 넘은 조각은 「넣지 못함」(held) · 지문이 어긋나면 E_CONFLICT 로 아무것도 쓰지 않음 · 조각 없는 기록은 메모.
  • 들이기(팀 일꾼) · 팀 파일 넣기(20개) · 고치기(바로 문서에 · 정정 기록) · 넣지 못함 화면 · 대량 넣기(kmd-parse + 스킬 kmd-team-import) · 보내기(글마다 저장 한 번) · 정리 걷기 · 문서 다듬기 · ### 올리기.
  • 항목마다 되돌리기 · 「옛 값 → 새 값」 이력 · 하루 상한(E_RATE) · savelog 측정 도구.
  • 기준 문서(권한 모델 · 작성기준 · 컨벤션 · CLAUDE.md)를 같은 커밋에서 맞춤.

남은 것
