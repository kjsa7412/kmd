**반박이 붙은 kmd-seed 결론(직접 확인함)**

판정은 harness 를 유지합니다. 제품 코드는 한 줄도 돌지 않았습니다(`kn/real-1/kmd-seed` 에 pack 폴더가 없음). 그러나 진단이 댄 원인 「스킬 글의 상대 꼴 명령이 허락 접두와 어긋났다」 는 받아들이지 않습니다.

1. 결과 JSON `channels.kmd-seed.rows[0].session.result` 에서 세션이 실행하겠다고 적은 6개 명령은 모두 `node C:/project/kmd/scripts/kmd-seed.mjs …` 절대 꼴입니다. 상대 꼴은 첫 문장에서 명령 이름을 말할 때 한 번 나올 뿐입니다.
2. kmd-migrate 스킬 글(SKILL.md:24-33)도 상대 꼴인데 정상으로 돌았습니다. 그러니 상대 꼴로는 두 채널의 차이를 설명할 수 없습니다.
3. 실제 차이는 허락 규칙의 모양입니다. seed 는 `Bash(node C:/…/kmd-seed.mjs:*)` 하나뿐이고(scripts/channel-eval.mjs:1121), migrate 는 `Bash(node C:/…/kmd-migrate.mjs check:*)` 처럼 하위 명령마다 줬습니다(:1196). 이 밖에 cd · ls · `2>&1` 같은 덧붙인 셸 명령도 후보로 남습니다.
4. `session.checks` 는 진단이 적은 0 이 아니라 4 입니다. 이 값은 :1124 가 출력 전체에서 「kmd-seed.mjs check」 문자열을 센 것이라 실제로 돈 횟수가 아닙니다.
5. `r.out` 과 `permission_denials` 를 남기지 않아(:1123-1125) 거절된 명령 글은 확인할 수 없습니다.
