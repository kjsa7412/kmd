3.2_SCADA연계설계/PLC연계규격서.md · 첫 문장 11
항목더한 첫 문장
개요표기 [확인] · [협의] · [제안] 은 확인할 항목, 양쪽이 정할 항목, 이 규격의 기본값을 가른다.
문서 정보WBS 3.2.1 PLC 연계 규격서의 판은 v0.5(2026-10-18)이고 상태는 초안이다.
원칙연계의 원칙은 판단은 PLC 가 하고 게이트웨이 · DPMS 는 요청과 기록만 하며, 명령은 한 번이고 시간으로 실패를 정하지 않는 것이다.
연결게이트웨이는 클라이언트(마스터), PLC 는 서버(슬레이브)로 Modbus TCP 연결을 PLC 마다 하나 상시 유지한다.
명령 처리 규약PLC 는 명령 번호(W1)가 바뀌면 판단 순서를 거쳐 접수 결과와 동작 결과를 쓰고, 게이트웨이는 쓰기와 결과 읽기를 맡는다.
생존 확인 · 판정생존 확인은 읽기 응답과 PLC 시각 초 값으로 링크 상태를 DOWN · UP · STALLED · MAP_DIFF 로 판정한다.
주기 · 통신량상태 읽기는 1초(통신량 제한 개소 3초), 접수 읽기는 0.5초 주기이고 개소당 통신량은 약 5 ~ 10 kbps 다.
게이트웨이 설정 규칙 (매핑표 → 기준정보)받은 매핑표는 규칙에 따라 게이트웨이 기준정보 gt_link · gt_site · gt_fclt · gt_map_iem 등으로 옮기고 매핑표 반영 도구로 적재한다.
보안Modbus TCP 는 인증이 없어 VPN · 방화벽으로 출발지와 포트 502 를 제한하고, 게이트웨이는 명령 영역 밖으로 쓰지 않는다.
확장 · 상한개소 · 설비가 늘어도 규격과 게이트웨이 코드는 고치지 않고 기준정보 행을 추가해 늘린다.
이전 판에서 남는 것 · 없어지는 것이전 판에서 멱등 처리 · 생존 확인 · 블랙박스 등은 남고, 통신 상대와 프로토콜은 바뀌고, 프레임 형식과 SBO 는 없어졌다.
8.3_설치준비/운영절차서.md · 첫 문장 11
항목더한 첫 문장
개요표기는 확인 · 협의 · 제안 · 재계산 필요 넷이고, 설치 폴더는 기본값(게이트웨이 C:\dpms-gw, DPMS 웹 C:\dpms-web)으로 적는다.
문서 정보사업은 합천군 배수펌프장 통합운영관리시스템(DPMS) 구축이고, 작성은 사경진 과장, 기준일은 2026-10-18, 상태는 초안이다.
점검점검은 매일(상황실 운영자) · 매주(시스템관리자) · 현장 방문 때(DPMS 개발) 세 주기로 한다.
표시 상태의 뜻과 첫 대응상황 지도 색은 코드 DP002 표시 상태를 판정 순서대로 보이며, 상태마다 먼저 볼 곳과 첫 대응이 정해져 있다.
경보 대응경보는 PLC 경보와 DPMS 판정 경보로 나뉘고, PLC 경보는 상황실 기존 운영 규정을, DPMS 판정 경보는 경보마다 정한 대응을 따른다.
원격 제어 (상황실 운영자)원격 제어는 CTRL 이상 권한의 상황실 운영자가 주배수펌프 기동 · 정지 명령을 확인 창으로 한 번 보내고 PLC 결과를 확인하는 절차다.
기록 · 로그 위치기록 · 로그는 게이트웨이(제어망 PC)와 DPMS 웹(행정망 서버) 두 자리에 파일과 DB 표로 남는다.
보존 · 디스크보존 기간은 자리 · 대상마다 설정 키로 정하며, 사건 · 경보 · 명령 · 감사 · 로그인 기록은 지우지 않는다.
서비스 시작 · 정지 · 재시작게이트웨이 dpms-gw 와 DPMS 웹 dpms-web 서비스는 관리자 PowerShell 의 Restart-Service 등으로 시작 · 정지 · 재시작한다.
패치 (현장)패치는 반입 승인을 받아 현장에서 설치 절차서 7절대로 갱신하고 설치 확인표를 다시 확인하는 순서로 한다.
남은 확인남은 확인은 원격 제어 운영 규정 · 비밀값 교체 주기 · 백업 대신 할 일 · 블랙박스 보존처럼 대상과 협의하거나 확인할 항목이다.
3.3_게이트웨이설계/게이트웨이프로그램설계서.md · 첫 문장 10
항목더한 첫 문장
개요: 판 · 상태 · 근거 · 표기상태는 초안이고 기준 요구사항은 PLC 연계 요구사항정의서 v0.2 이며, 판마다 개정 내용과 같이 보는 계약을 적는다.
원칙: 설계 원칙설계 원칙은 판단은 PLC 부터 명령 영역에만 쓴다까지 P1 ~ P8 이다.
실행환경: 실행 환경 · 기술 선택게이트웨이는 Java 17 · Spring Boot 3.2.6 실행형 jar 와 같은 PC 의 PostgreSQL 16 으로 돌며 WinSW 로 Windows 서비스가 된다.
