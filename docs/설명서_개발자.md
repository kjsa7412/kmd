# kmd 설명서: 개발자

Node 20 이상(PC 꾸러미는 node 22 를 싣는다) · ESM · 의존성 셋(js-yaml · markdown-it · pg: pg 는 DB 가져오기). 빌드 단계 없음. 화면은 목업의 글 틀 그리기를 그대로 옮긴 순수 ES 모듈.

## 이 PC 의 판 자리

설치 한 줄은 PC 꾸러미를 `~/.kmd-app/versions/<판>` 에 풀고 `kmd pc link` 로 지금 판(`current.json`)과 실행기(`~/.kmd-app/bin/kmd.cmd` · `kmd-key.cmd`)를 세운다. PATH · 늘 켜기 작업 · 시작 메뉴의 kmd(`kmd open`) · Claude Code 헤더 도우미는 실행기만 부른다. 판을 바꿔도 다시 걸 일이 없다(`core/pcops.js`). 실행기는 자기 자리(`%~dp0`) 기준 상대 경로를 쓴다. cmd 가 .cmd 를 시스템 코드 페이지로 읽어 한글 사용자 폴더의 절대 경로가 깨진다. 저장소에서 돌면(`node server/bin/kmd.mjs`) 판 자리가 아니라 예전처럼 node 와 스크립트 경로를 그대로 쓴다.

이 PC 의 kmd 화면은 한 번용 번호로만 들어온다. `kmd up` 은 다 켜진 뒤 `<살림 자리>/up.json` 에 주소를 적고, `kmd open` 은 그 kmd 에게 이 PC 의 열쇠(자격 저장소의 기기 열쇠)로 번호를 받아(`POST /api/pc/once`) 브라우저를 연다. 설명서는 `/manual`(docs 의 설명서 넷: 꾸러미에도 싣는다).

## 자리

| 폴더 | 무엇 |
|---|---|
| `core/` | 지식 읽기(knowledge · sections · vocab · registry) · 저장(save: 기록 하나 + 항목 + git 한 묶음) · 찾기 사다리(search) · 정리(curate · tidy · worker) · 백업 · 원천(sources · baseline) · 넣기(importer · ooxml) · 보내기(send) · 되살리기(restore) · 들어가기(auth · passwd · keystore) · 에이전트(kit) |
| `server/` | `hub.js`(모든 길의 가운데: 화면 · MCP 가 같은 길) · `http.js`(길 · 들어가기 · CORS) · `mcp.js`(brief · match · search · section · save) · `views.js` · `bin/kmd.mjs` |
| `app/` | 화면: `main.js` 한 장 · `kmd.css`(목업 CSS) |
| `agent/` | 에이전트 설치가 까는 스킬 셋(kmd-work · kmd-save · kmd-build: kmd-build 는 가져오기의 에이전트도 쓴다) · CLAUDE.md 덩이 |
| `test/` | 판마다 필수 시험(`node --test test/<판>.test.mjs`) · `fixture/kmd`(dpms · gdi) · 가짜 claude 둘 |
| `scripts/` | `pack.mjs`(꾸러미) · `kmd-install.sh`(팀 서버) |

## 지식 = md 폴더

`docs/**.md`(항목 = `## 머리`) · `work/<id>.md`(기록: frontmatter id · title · date · author · touches · tags …) · `_vocab.md`(이름 장부) · `_managed.md`(자리 장부) · `docs/assets`(첨부) · kmd 가 쓰는 파일 `_members.md` · `_sources.json` · `.kmd.json`. 살림 자리 `<root>/.kmd`(명부 · 상태 · 비밀 · 색인).

## 지키는 것

- 쓰는 길은 `core/save.js` 하나: 기록은 늘 남는다 · 같은 지식의 저장은 한 줄로 선다 · 실패하면 되돌린다.
- 자동 쓰기는 정해진 작성자 · 태그만(kmd · kmd-auto · kmd-worker / edit · curate-auto · curate-llm · sources · code-change …): 끝 시험이 그 밖의 무인 커밋을 센다.
- 화면 말에 금지어 0(`test/screen-kmd.test.mjs` 의 BANNED).
- 비밀은 셸 숨김 입력 · `secrets.json` 에만: 화면 · 로그 · 응답 · 선언에 0.

## 시험

```bash
node --test test/k0.test.mjs
```

PC 를 같이 쓰므로 한 번에 하나씩. 화면 시험은 이 PC 의 Chrome(playwright-core)을 쓰고 목업과 나란히 그림을 남긴다(`%TEMP%\kmd-shots`). 시험은 임시 폴더 · 빈 포트 · 임시 HOME/APPDATA 만 쓴다.

셸 명령을 돌리는 시험(`test/open.test.mjs` · `.kmd-data` 의 손 확인)은 환경 변수로 이 PC 를 바꾸지 않는다.

| 변수 | 막는 것 |
|---|---|
| `KMD_NO_TASK` | connect · pc update 의 작업 스케줄러와 시작 메뉴, open · up · pc restart 의 `schtasks /Run` · `/End` · `/Query`. `kmd pc task` 는 막지 않는다. 시험은 `--print` |
| `KMD_NO_BROWSER` | 브라우저를 띄우지 않고 `[열 주소] …` 한 줄을 찍는다 |
| `KMD_NO_CLAUDE` | Claude Code 설정(`claude mcp …`)을 부르지 않는다 |
| `KMD_APP_HOME` | 판 자리(기본 `~/.kmd-app`) |
| `KMD_PC_ROOT` | 이 PC 의 기본 지식 폴더(기본 `D:\kmd` · 집 폴더의 kmd) |
| `KMD_NO_BACKUP` | connect 가 다른 드라이브에 백업 자리를 만들지 않는다 |
| `KMD_NO_PATH` | 설치 한 줄(PowerShell)이 사용자 PATH 를 건드리지 않는다 |

자격 저장소는 `APPDATA`(Windows) · `XDG_CONFIG_HOME` 을 임시 폴더로 주면 그 안에 쓴다. 포트는 `--port 0`: 7373 은 쓰지 않는다.
