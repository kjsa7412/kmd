# kmd 설명서 — 관리자

팀 서버를 세우고 사람 · 백업 · 정리 로그인을 돌본다. 밤 묶음 · 되살리기는 [kmd_운영.md](kmd_운영.md).

## 세우기

```bash
sudo sh kmd-install.sh --team --url http://kmd.team.local --gitlab-group team --gitlab-api https://gitlab.team.local
```

- node 22 · git 이 있어야 한다. `/opt/kmd` 에 깔고 systemd(kmd.service)로 늘 켠다. 지식은 `/srv/kmd/<지식>/`.
- GitLab 열쇠는 숨김 입력으로만 받는다 — **만들기 권한만** 있는 봇 열쇠(지우기 · 보호 해제 없음). 지식마다 저장소를 저절로 만들어 백업 자리로 붙인다.
- 끝에 찍힌 **첫 설정 주소**를 브라우저로 연다 → 관리자 아이디 · 비밀번호 두 칸.
- PC 꾸러미(`kmd-<판>-pc.zip`)를 `/srv/kmd/.kmd/dl/` 에 두면 설치 한 줄이 kmd 가 없는 PC 에 받는 곳을 알려 준다.

## 관리 화면 — 문제 줄만

- **비밀번호를 안 정한 사람** — [링크 만들기] 로 처음 들어오기 링크를 한꺼번에(24시간 · 한 번). 메신저로 사람마다 따로 보낸다.
- **잠김** — 여러 번 틀린 자리는 잠시 막힌다(맞는 사람은 그대로 쓴다). [풀기].
- **관리자에게 부탁** — 사람이 더해 달라는 가져오는 곳. [더하기].
- **자동 정리가 쉬고 있다** — 정리 전용 Claude 로그인이 끝났거나 한도. 아래 Claude 연결에서 다시.
- **백업이 앞섰다 · 갈라졌다** — 어느 쪽이 맞는지 정한다. [백업에서 받기](앞으로만) · [이 백업 이어 쓰기](지금 것은 가지로 남는다).

## Claude 연결 — 정리 전용 로그인

1. 관리 › Claude 연결 › [로그인 시작] → 비밀번호 한 번 더.
2. 서버가 띄운 로그인 주소를 연다 → Claude 에 들어가 받은 번호를 붙여 넣는다(한 번용 · 저장하지 않는다).
3. 「로그인됨 · 정리 전용」. 오래 가는 열쇠는 서버 비밀에만 있다(화면 · 로그에 없다).
4. 정리 일꾼은 서버에서 `kmd worker <팀 주소> --data /srv/kmd/.kmd` 로 띄운다(정리 전용 OS 사용자 · 일꾼 열쇠는 `kmd worker add`).

사내 https 가 생기면 그 뒤에서 하길 권한다.

## 셸 명령

| 명령 | 하는 것 |
|---|---|
| `kmd user add <아이디> [--admin]` | 사람 더하기 — 처음 들어오기 링크를 찍는다 |
| `kmd user reset <아이디>` | 비밀번호 다시 정하기 링크(마지막 관리자가 잊었을 때도) |
| `kmd backup add <지식> <주소>` | 백업 자리 붙이기 |
| `kmd secret set <이름>` | 비밀 넣기(gitlab · 원천 git 자격 등) — 숨김 입력 |
| `kmd machine add …` | 바깥 생성기용 기계 열쇠(그 지식 · 그 표만) |
| `kmd search-check` | 찾기 점검 — 얼린 시험지 위에서 나빠진 문항 |
| `kmd restore <백업 주소>` | 지식 되살리기 |
| `kmd auth reapply <auth.log>` | 옛 명부로 되살린 뒤 늦은 일 다시 적용 |
