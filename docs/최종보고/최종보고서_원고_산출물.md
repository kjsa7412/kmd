# KMD 최종보고 원고 · 산출물 판

`KMD_산출물.html` 의 구획 원고다. 개념 위주인 `KMD.html`(원고 `최종보고서_원고.md`)의 다른 판으로, **실제로 만든 화면**을 찍어 주요 기능을 그 화면으로 보인다.
첫 화면 · 문제 · 해결 · 원칙 · 순환 · 개인 지식 · 비교 · 맺음은 기존 판 것을 쓰고, 나머지 개념 구획(구조 · 장부 · MCP · 채널 · 변환)을 실제 화면 구획(산출물 · 문서 · 항목 · 기록 · 그래프 · 수집 채널)으로 바꿨다. 비교 다음에 채널 평가 장(평가)을 더했다.
