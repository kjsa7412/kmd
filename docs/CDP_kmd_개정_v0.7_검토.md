## 0. 운영자의 말 · 결론

> 팀 브라우저든 개인이던 프로그램에서 기록문서를 만들던 정리를 하던 cli 를 로그인하는 것이 설정에 있어야 한다. + 에이전트 설치(skill, mcp 관련 설치) 등. 그리고 기존 뷰어에 문서, 기록, 그래프가 있을 텐데 이걸 완전 개편하고자 한다. 뻗어나가기 그런 건 없고 문서를 기반으로 문서를 보던 좌표를 기반으로 문서를 보던 2가지로 구분하고 그래프로 보는 건 별도로 보는 방식으로 하자. 그래서 총 3가지 방법으로 보는 건데 '옵시디언' 프로그램을 벤치마킹하자. — 운영자, 2026-10-22

**결론 — 받아들인다.**
> 1. 보는 법은 **셋**이다 — **「문서로 보기」**(폴더 · 문서 나무 → 문서) · **「항목으로 보기」**(이름표 목록 → 그 항목의 지금 + 이력) · **「그래프」**(따로 한 화면). 왼쪽 끝 세로 띠(옵시디언의 리본)의 아이콘 셋으로 바꾼다.
> 2. CDP 의 **뻗어나가기 열 · 「읽기」 의 문서/기록 세그 · 3D 좌표 그래프는 걷는다.** 기록은 「문서로 보기」 나무의 「기록」 폴더와 「항목으로 보기」 의 이력으로 들어간다.
> 3. 옵시디언에서 가져오는 것 — 왼쪽 나무 · 가운데 탭 · 오른쪽 옆 칸(개요 · 이 문서를 가리키는 것 · 속성) · 빨리 열기(Ctrl O) · 명령 창(Ctrl P) · 링크 미리보기 · 그래프의 거름 · 색 묶음 · 깊이. 가져오지 않는 것 — 캔버스 · 플러그인 · 손으로 쓰는 `[[링크]]` 를 지식의 뼈대로 삼는 것(kmd 의 뼈대는 항목 이름표다).
> 4. 설정에 **「Claude 연결」**(이 프로그램이 쓰는 Claude Code 로그인 — 상태 · 로그인 · 다시 로그인)과 **「에이전트 설치」**(작업 폴더마다 스킬 · MCP · 안내 한 덩이 — 상태 · 설치 · 모두 최신으로)를 둔다. 내 PC 프로그램은 화면에서 끝나고, 팀 화면은 관리자만 · 서버에서 도는 로그인 흐름을 화면이 이어 준다.

> **쉬운 말로 — 다섯 줄**
> 1. 지식은 세 가지로 본다 — **폴더와 문서로**, **항목(이름표)으로**, **그래프로**. 왼쪽 끝 아이콘 셋으로 바꾼다.
> 2. 문서로 볼 때는 옵시디언처럼 왼쪽 나무에서 문서를 열고, 탭으로 여러 개를 띄우고, 오른쪽에 목차와 「이 문서를 가리키는 것」 이 붙는다.
> 3. 항목으로 볼 때는 「배포절차 › 헬스 체크」 같은 항목 하나를 고르면, 그 항목의 지금 글 · 아직 문서에 안 넣은 기록 · 지난 기록이 한 화면에 모인다.
> 4. 그래프는 따로 연다. 항목 · 문서 · 기록을 점으로, 「건드렸다 · 들어 있다 · 바로잡았다 · 가리킨다」 를 선으로 그리고, 거름과 깊이로 줄인다. 점을 누르면 위의 두 보기로 간다.
> 5. 설정에서 **Claude 로그인**과 **에이전트 설치**(Claude Code 에 kmd 를 붙이는 일)를 한다 — 상태가 보이고, 안 되어 있으면 단추 하나다.

CDP 가 3D 좌표 그래프를 고른 까닭(`CoordGraph.jsx:3-11` — 문서 노드 31 · 간선 1, 좌표 노드 55 · 간선 65 · 「CDP 의 기록은 서로를 링크하지 않고 좌표를 통해서만 만난다」)은 **kmd 에서도 맞다.** 그래서 kmd 그래프의 기본 점은 **항목**이고 문서 · 기록은 거름으로 켠다. 달라진 것 하나 — kmd 의 내 지식은 보통 md 폴더라 **문서끼리의 링크(`[...](...)` · `[[...]]`)가 실제로 있다.** 그래서 「가리킨다」 선을 더한다(§4).

## 2. 보기 하나 — 「문서로 보기」(옵시디언의 파일 탐색기 + 편집기 + 옆 칸)

```
┌리본┐┌ 왼쪽: 나무 ───────────┐┌ 가운데: 탭 · 문서 ─────────────────────┐┌ 오른쪽 옆 칸 ─────────┐
│ 문서│ DPMS 지식              ││ [배포절차] [회의록-1021] [+]            ││ 개요                   │
│ 항목│ ▾ 문서                 ││ 배포절차                                ││  준비 · 카나리 · 헬스… │
│ 그래│   배포절차 ●           ││ ## 헬스 체크   kmd 가 정리 · 02:31     ││ 이 문서를 가리키는 것  │
│ 프  │   운영                 ││ …                                       ││  기록 12 · 문서 2      │
│     │ ▾ 기록 (날짜 순)       ││ ▸ 아직 문서에 안 넣은 기록 1            ││ 속성                   │
│     │   10-22  롤백 순서     ││ [저절로 채우는 표 · dpms-api · 10:00 확인]││  정리 02:31 · 가져오는 곳│
│     │ ▾ 받은편지함           ││                                         ││                        │
└─────┘└───────────────────────┘└─────────────────────────────────────────┘└────────────────────────┘
```

| 부분 | 옵시디언에서 | kmd 에서 |
|---|---|---|
| 왼쪽 나무 | 파일 탐색기 — 폴더 · 파일 · 정렬 · 새 파일 | 지식 → 「문서」(관리 문서 · 등록부 밖 문서 · 폴더 그대로) · 「기록」(날짜 순 · 내 기록 거름) · 「첨부」. 줄 끝 표시 — ● 아직 안 넣은 기록이 있는 문서 · 노랑 값이 바뀐 것 |
| 가운데 | 탭 · 화면 나누기 · 읽기/편집 전환 · 링크에 마우스를 올리면 미리보기 | **탭**(열린 문서 · v1 의 「열린 문서 탭」 을 이어 씀) · **나누기**(두 문서 나란히 — 비교에 쓴다) · 읽기 ↔ 고치기 한 단추 · 항목 이름 · 링크에 올리면 **미리보기 카드**(그 항목의 첫 줄 · 정리 시각) · 문서 안 항목 머리 옆 표지(「kmd 가 정리 · 02:31」) · 저절로 채우는 표(회색 잠김) |
| 오른쪽 옆 칸 | 개요 · 백링크(링크된 것 · 언급만 된 것) · 속성 | **개요**(항목 목차 — 지금 `SectionRail` 을 옮김) · **이 문서를 가리키는 것**(이 문서의 항목을 건드린 기록 n · 이 문서를 링크한 문서 n · 이름만 나온 곳 n — 옵시디언의 「링크 · 언급」 둘을 그대로) · **속성**(마지막 정리 · 가져오는 곳 · 주인 · 내 PC/팀) |
| 기록을 열면 | — | 기록도 같은 가운데에서 열린다. 옆 칸은 「이 기록이 건드린 항목」 · 「바로잡은 / 바로잡힌 기록」 |

- **뻗어나가기를 대신하는 것** — 옆 칸 「이 문서를 가리키는 것」 과 링크 미리보기 · 탭 · 「‹ 이전」 이 그 일을 한다. 관계를 열 단위로 펼치지 않고, 지금 보는 것의 이웃 한 겹만 옆에 둔다(옵시디언의 방식).

## 3. 보기 둘 — 「항목으로 보기」(옵시디언의 태그 창 + 속성 기준 보기)

```
┌리본┐┌ 왼쪽: 항목 목록 ──────────┐┌ 가운데: 항목 한 화면 ─────────────────────────────────┐┌ 옆 칸 ─────────┐
│     │ 찾기 [            ]       ││ 배포절차 › 헬스 체크          다른 이름: 상태 점검    ││ 같이 나오는 항목│
│     │ ▾ 화면 12                 ││ 지금 — (문서 배포절차 안의 그 항목 글)               ││  롤백 · 모니터링│
│     │ ▾ 절차 8                  ││ 아직 문서에 안 넣은 기록 1 — 10-22 이 · /healthz      ││ 들어 있는 문서  │
│     │   헬스 체크 ● 3           ││ 지난 기록(이력) — 10-21 · 10-20 바로잡음 · 10-14     ││  배포절차       │
│     │   롤백                    ││ 이 항목을 쓰는 곳 — 장애 대응 › 처음 10분 …          ││ 가져오는 곳 표  │
│     │ ▾ 테이블 270              ││                                                       ││                 │
└─────┘└──────────────────────────┘└───────────────────────────────────────────────────────┘└─────────────────┘
```

- **왼쪽** — 이름표(좌표)를 **종류로 묶은 목록**(화면 · 절차 · 테이블 · API · 용어 … — 화면 말은 「종류」 · 「항목」). 줄마다 기록 수 · ● 아직 안 넣은 것 · 노랑 값이 바뀐 것. 맨 위 찾기 칸은 v0.6 의 찾기 사다리(이름이 안 맞으면 「비슷한 항목」). 거름 — 「아직 안 넣은 것만」 · 「최근 바뀐 것」 · 「내가 쓴 것」.
- **가운데 — 항목 한 화면.** CDP 의 `section` 이 주는 것을 그대로 한 장에 — **지금**(그 항목이 든 문서의 그 부분) · **아직 문서에 안 넣은 기록** · **지난 기록(이력)**(그 항목을 건드린 기록을 날짜 순으로 · 바로잡은 것은 위에) · **이 항목을 쓰는 곳**(다른 항목 글에 이름이 나온 곳) · **다른 이름**. 「이 항목은 어디에 있나」 를 묻지 않고 바로 본다 — 운영자의 「좌표를 기반으로 문서를 본다」.
- **옆 칸** — 같이 나오는 항목(같은 기록이 함께 건드린 항목 · 많은 순) · 들어 있는 문서 · 저절로 채우는 표(있으면).
- 문서가 아직 없는 항목(기록만 있는 것)도 목록에 나온다 — 가운데가 「아직 문서에 없다 — 기록 n 이 같이 읽힌다」.

## 4. 보기 셋 — 「그래프」(옵시디언의 그래프 뷰 · 따로 한 화면)

| | 옵시디언 | kmd |
|---|---|---|
| 점 | 문서(첨부 · 태그는 선택) | **항목**(기본) · 문서 · 기록 · 가져오는 곳 — 종류마다 켜고 끈다. 기본은 항목 + 문서 |
| 선 | 링크 | **들어 있다**(문서 ⊃ 항목) · **건드렸다**(기록 → 항목) · **바로잡았다**(기록 → 기록) · **가리킨다**(문서 → 문서 링크 · 항목 글 속 다른 항목 이름) · **채운다**(가져오는 곳 → 항목) |
| 줄이기 | 거름(찾기 · 태그 · 고아) · 색 묶음 · 지역 그래프 깊이 · 힘 조절 | **거름**(찾기 · 종류 · 「아직 안 넣은 것만」 · 기간 — 「최근 30일 기록」) · **색 묶음**(종류마다 · 「값이 바뀐 것」 노랑) · **깊이**(고른 점에서 1 · 2 · 3 겹) · 외톨이 숨기기 |
| 열기 | 점 누르면 그 문서 | 점을 누르면 **옆 카드**(이름 · 첫 줄 · 기록 수) → 「문서로 보기」 · 「항목으로 보기」 로 연다 |
| 지역 그래프 | 문서 옆 칸에 그 문서 중심 그래프 | 「문서로 보기」 · 「항목으로 보기」 의 옆 칸 접힘 「이웃 그래프」 — 깊이 1, 누르면 그래프 화면으로 |

- **2D 로 바꾼다.** CDP 의 3D 는 점이 수십 개일 때 덩어리가 보였지만(`CoordGraph.jsx`), kmd 는 거름 · 색 · 깊이로 줄이는 쪽이 낫다 — 옵시디언과 같은 손맛이고, 화면을 돌리는 손이 없다. 크기 예산 — gdi 의 테이블 항목 270 같은 큰 종류는 묶음 점(「테이블 270」) 하나로 접고, 누르면 편다.
- 의존성 0 원칙(폐쇄망)은 그대로 — 그림 라이브러리를 들이지 않고 캔버스 · 간단한 힘 배치를 손으로 쓴다(지금 `CoordGraph` 와 같은 원칙).

## 5. 셋을 잇는 것(옵시디언의 손맛)

| 기능 | 키 | 무엇 |
|---|---|---|
| 리본 | — | 왼쪽 끝 세로 띠 — 문서 · 항목 · 그래프 · (아래) 설정. 보는 법을 바꿔도 **열린 탭은 그대로** |
| 빨리 열기 | Ctrl O | 문서 · 항목 · 기록 이름으로 바로 열기(지금 `Palette` 를 다듬음) |
| 찾기 | Ctrl K | v0.6 찾기 사다리 — 문서의 항목 / 비슷한 글 / 「이 말로는 못 찾았다」 |
| 명령 창 | Ctrl P | 「지금 정리」 · 「자료 가져오기」 · 「지식 추가」 · 「나누어 보기」 … 화면의 일을 이름으로 |
| 탭 · 나누기 | Ctrl T · Ctrl \ | 세 보기 모두 가운데는 탭. 나누기로 문서 둘 · 문서와 항목을 나란히 |
| 이전 · 다음 | Alt ← → | 보는 법을 넘나들어도 한 줄로 돌아간다(v0.24 문서 이동을 이어 씀) |

옆 메뉴(v0.6 셸)는 **일**(오늘 바뀐 것 · 자료 가져오기 · 보내기 · 정리 · 설정)을 맡고, 리본은 **보는 법**을 맡는다. 옆 메뉴의 「지식 목록 · 문서 · 그래프」 세 줄은 리본으로 옮기고 「지식 목록」 은 리본 위 지식 고르기(지금의 지식 전체 ▾)로 합친다.

## 6. 설정 — 「Claude 연결」(운영자 요구 1)

기록 문서를 만들거나(들이기 · 세션 밖에서 글을 짓는 일) 정리할 때 kmd 는 Claude Code(`claude` CLI)를 부른다(v0.6 §6.2 — 서버 프로세스가 아니라 일꾼 · 도구 0). 그 로그인을 **설정 한 곳**에서 보고 고친다.

| 자리 | 화면 | 하는 일 |
|---|---|---|
| **내 PC 프로그램** | 설정 › Claude 연결 — 「로그인됨 · kim@… · 남은 날 300」 / 「로그인 안 됨」 + **[Claude 로그인]** | 누르면 PC 프로그램이 `claude` 로그인을 띄운다 — 브라우저가 열려 Claude 에 들어가면 끝(오래 가는 로그인 권장 · 그 PC 의 OS 자격 저장소). 「이번 달 정리 n건」 · [다시 로그인] · ⋯ 「Claude 쓰지 않기」 |
| **팀 서버(관리자만)** | 관리 › Claude 연결 — 정리 전용 로그인(KM84) 상태 · 쓰는 곳(정해진 정리 · 지금 정리 · 기록 만들기) · **[로그인 시작]** | 관리자 재인증(비밀번호) 뒤, 서버가 정리용 OS 사용자로 `claude` 로그인 흐름을 띄우고 **그 흐름이 내는 주소와 번호를 화면이 그대로 보여 준다** — 관리자가 주소를 열어 Claude 에 들어가고, 받은 번호를 화면 칸에 붙이면 끝. 셸에 들어갈 일이 없다(v0.6 정정 ③ 의 「비밀은 셸」 예외 — 이 칸은 **한 번용 인증 번호**이고 저장하지 않는다 · https 가 아니면 「사내 https 뒤 권장」 한 줄) |
| **팀 화면 · 일반 사용자** | 설정 › Claude 연결 — 읽기만: 「팀 정리는 정리 전용 로그인으로 돈다 — 쉬면 관리자에게 알린다」 · 내 PC 프로그램이 있으면 그 Claude 상태 한 줄 | — |

- 로그인이 끝나면 v0.6 의 멈춤 한 줄(「자동 정리가 쉬고 있다 · 2일 — 관리자에게 알렸다」) 이 이 설정 칸으로 가는 링크를 단다.
- **확인할 것(추정)** — `claude` 로그인 흐름이 화면 없는 서버에서 주소 · 번호를 내는 모양인지, 오래 가는 로그인(`setup-token`)이 같은 흐름인지는 L2a 스파이크에서 잰다. 안 되면 팀 서버는 지금처럼 「서버에서 한 줄」 로 돌아간다(화면은 상태만).

## 7. 설정 — 「에이전트 설치」(운영자 요구 1)

Claude Code 가 kmd 를 쓰려면 작업 폴더(코드 레포)에 **스킬(cdp-work · cdp-save 류) · MCP 연결(키 두 개 — 팀 · 내 PC) · 안내 한 덩이(CLAUDE.md)** 가 놓여야 한다(CDP 의 kit · `cdp-install.mjs` · `core/localreg.js`). 이것을 설정에서 본다.

| 자리 | 화면 | 하는 일 |
|---|---|---|
| **내 PC 프로그램** | 설정 › 에이전트 설치 — 이 PC 의 작업 폴더 목록(이름 · 경로 · 상태 「최신 · v1.13」 / 「옛 판 — 고침 있음」 / 「없음」) · **[폴더 더하기]**(경로 칸 하나) · ⋯ 빼기 | 폴더를 더하면 PC 프로그램이 그 폴더에 스킬 · MCP(두 키 · 열쇠는 저장소에서 — v0.6 KM61) · 안내 블록을 놓는다. **새 판이 오면 저절로 모두 최신으로**(v0.6 KM73) — 단추는 「지금 모두 최신으로」 하나(⋯ 안). 폴더에 사람이 고친 안내가 있으면 그 줄은 그대로 두고 kmd 블록만 바꾼다 |
| **팀 화면** | 설정 › 에이전트 설치 — 「이 PC 의 Claude Code 로 쓰려면 — 설치 한 줄 복사」(10분 · 한 번 · v0.6 §3.3) · 내 기기 목록(어느 기기에 깔렸나 · 마지막 사용 · 판) | 브라우저는 PC 폴더를 못 쓰므로 한 줄로 한다. 한 줄이 내 PC 프로그램이 있으면 그 프로그램에 폴더를 더하고, 없으면 그 폴더에만 놓는다 |
| **관리자** | 관리 › 에이전트 — 팀 기본 스킬 판 · 「옛 판으로 붙은 기기 n」 | — |

- 무엇이 깔리나는 「자세히」 안에 — 스킬 이름 · MCP 키 · 안내 블록 줄 수. 화면 말은 「Claude Code 에 kmd 를 붙인다」 · 「최신」 · 「옛 판」.

## 10. 단계
