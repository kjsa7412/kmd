배포절차

배포 · 롤백 · 헬스 체크 · 카나리 · 태그 규칙을 한 곳에 둔다.

롤백

배포 뒤 10분 안에 오류율이 2% 를 넘으면 롤백한다. 롤백은 직전 이미지 태그로 되돌리는 한 줄이다 — deploy.sh --tag <직전 태그>.

마이그레이션이 든 배포는 down 스크립트를 먼저 돌고, 롤백 전에 DBA 에게 확인한다.

헬스 체크

각 서버의 /health 를 30초마다 부른다. 시간 초과는 5초다.

세 번 연속 실패하면 그 서버를 로드밸런서에서 뺀다. 빠진 서버는 사람이 확인하고 다시 넣는다.

카나리 단계에서는 카나리 서버만 본다.

김이 고친 안 1 — 아직 반영 전·보기

카나리

카나리는 전체의 10% 로 시작한다. 10분 동안 오류율이 0.5% 를 넘지 않으면 25% → 100% 로 넓힌다. 넘으면 바로 롤백한다.

야간(22~07시)에는 카나리를 열지 않는다.

태그 규칙

릴리스 태그는 main 의 머지 커밋에만 단다. 태그는 v<주>.<부>.<고침> 로 단다. 시험 판은 -rc.N 을 붙이고 운영에 올리지 않는다.
